# 0.2.59 遥操作单入口

侧栏只保留一个“遥操作”，页面内选择“虚拟预览”或“实机跟随”。两种模式共用已有的手套、用户、标定模型、SDK 会话和显示区域。选择模式只改变本页画面与控件，不重新接入、导入标定、配手或启动跟随。原有 `#virtual-glove` 深链、标定后的下一步和任务视图路由仍指向同一页面与导航入口。

虚拟模式保持禁止配手和启动实机；已有或未确认的实机跟随仍可暂停。单入口不改变原来的会话、操作代次、数据新鲜度、停止与断开保护。画面大小设置仍然共用。

本版只调整前端导航与版本资料。标定保存与套用、多用户双侧资料、旧请求、防重复接入、更新和导出的完整修复及验收范围沿用 [0.2.58 记录](VALIDATION_0.2.58.md)。最终 Python 源码与 0.2.58 的 2527 项全量回归逐文件比对；该次回归零失败、零错误，3 项因环境条件跳过。前端改动另用完整页面和独立检查覆盖单入口、内部切换、旧链接、租约保持及响应顺序。

构建、安装载荷、本机版本、配置与 SDK 标定资料保留、源码同步结果另存于外部交付清单。没有连接或驱动实物；真实长时间连接及实机效果仍需接设备验收。
