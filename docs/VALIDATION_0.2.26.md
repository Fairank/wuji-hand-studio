## 磨砂与实际设备边界

本机pywebview系统主题处理会写入DWM背景类型1/2，覆盖工作台的类型3。新增事件恢复器以150ms合并通知，重申当前偏好；普通拖动不逐帧重设，不增加轮询、桌面采集或外部折射。只绑定自有HWND，不改变焦点或系统偏好。

配置回读不等于光学验收。Windows背景Acrylic在窗口失焦、系统减少透明或节能等情况下可能退成实色；本版处理返回窗口后不恢复、反复拨开关和旧结果覆盖新设置的问题。真实屏幕观感仍需用户验收，见[使用说明与微软来源](SIMPLE_MODE.md#磨砂恢复与系统行为)。

本轮没有使能设备、播放真实动作、开启遥操作跟随、开始手套标定或触觉清零。真实设备发现、数据画面、标定及动作仍需后续接入设备单独验证。历史测试的合成编号没有导入用户配置；没有根据扫描或CLI运行填入虚构连接记录。
