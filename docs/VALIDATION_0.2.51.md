# 0.2.51 同类故障排查与修复

本轮从固件缺少HOME、环境构造后未传入、原始错误被泛化这三条根因扩展排查。检查31个运行模块中的64处显式子进程启动，另检查注入runner、远程包装、软件更新、报告及支持包路径。以下是已复现并修复的8类问题。

| 类别 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 原生CLI用户目录 | 固件之外的元数据、发现、标定worker、Viewer仍各自拼环境，可能缺HOME | 共用原生环境函数；缺HOME时使用Windows用户目录，保留有效显式HOME及检查专用临时目录，不改父环境 |
| 无效目录与固件锁 | 相对或无效HOME可能在尚未启动写入进程时被误当未知刷写状态 | 在CLI身份预检时拒绝；未启动不误留写入锁，真正未知退出仍保持保护 |
| 相对控制端路径 | SDK检查与实际连接使用不同工作目录，可能检查不到或检查错Python | local检查cwd与控制端一致，CLI包装按同一目录解析相对执行路径 |
| Mac控制环境 | 部分Lima环境未传、组件检查使用错误平台、历史清单缺CLI基线 | 共享完整环境包装，使用macvm配置；仅为已知历史资源包提供固定兼容基线，不推断未知版本 |
| 诊断报告保存 | 保存失败会丢掉本次已取得的退出码、stdout和stderr | 保留本次内存报告与原始输出，单独提示保存失败 |
| 文件操作分类 | 权限、磁盘空间、文件路径错误被报为反馈通道异常；Mac打开目录可假成功 | 仅对已知文件动作返回固定OS分类，设备异常保护保持；Mac核验open进程退出码 |
| 软件更新反馈 | 泛化提示覆盖原始错误，带URL的磁盘错误还可能误报网络 | 可展开原始详情，文件错误优先分类；长路径换行滚动，重试清理旧详情 |
| 支持包不完整 | Mac官方ZIP未生成或收取失败时，本地简报与输出被丢弃；界面仍可能像成功 | 保留原始输出、简报及明确收取错误，排除残缺ZIP，官方包不存在时隐藏其链接 |

## 验证与保留边界

隔离全量回归2160项，0失败、0错误、2项环境跳过。原生环境专项33项通过，包含6个启动边界、固件预检和软件检查临时HOME隔离。控制端新增10项回归及相关检查通过，路径与导出20项隔离检查通过。无界面浏览器验证更新详情、长路径、重试清理及支持包缺失状态；附件响应头与精确UTF8字节通过实际Handler检查。

软件检查专用临时HOME保持隔离；不把Windows HOME传入WSL、SSH或Mac来宾。通用PTY/JSONL适配器继续继承已选控制环境。无设备自动连接、自动确认或自动刷写。此前未改动功能的验收记录保持，本轮没有声称完成实物或全部操作系统的原生验收。

本轮真实ConPTY测试受本机回环权限限制，只取得子Python收到环境的部分证据，未将其记为完整通过；上一版真实ConPTY验证单独保留。浏览器附件saveAs受环境限制取消，未冒报浏览器落盘成功。Mac流程使用合成控制端，未实际启动Mac桌面或安装系统组件。

实际本机版本、安装载荷、用户数据保留与源码同步记录在外部最终交付清单。源码版本不等于已发布新的安装包。
