## 标定界面精简

六姿势图卡、示意图、姿势选择器及其四个旧资源已删除，不再把 CLI 已有的采集/求解功能做成另一套流程。工作台保留单一 CLI 开始/取消入口、命名用户、手套/左右侧及覆盖确认，显示当前步骤、实际进度与结果；原始事件默认折叠。

在完全模拟接口的 Edge / Playwright 中验证中文 1308、960 像素和英文 700 像素界面，均无横向溢出或脚本错误。Browser 插件不可用，使用本机已安装的无界面 Edge；没有操作用户的浏览器或桌面。

- 命名用户创建/切换、左右侧、覆盖及开始/取消仍发送原有参数。
- 不再有可浏览的六个姿势、额外说明侧栏或姿势预览。
- 当前步骤只读官方步骤名称，或已确认总数为 6 的有效编号；缺失和未知步骤保持未知。
- 进度只读官方 0–1 数值；非法值、旧事件或经过时间不会推算新进度。蓝色 4px 进度条没有常驻动画。
- 只有非运行、状态 completed、退出码 0 且最后官方事件为 result 才显示完成。旧 result 后的错误/取消及未确认状态均不显示成功。
- 刷新失败保留上次事件并标为未核对；恢复后清读取错误，不抹掉操作失败或官方错误原文。

这证明的是模拟条件下的界面和协议行为，不是一次真实手套标定。
