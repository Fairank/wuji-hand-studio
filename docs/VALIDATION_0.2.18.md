# Windows 0.2.18 验证

范围：在同一个 Hand Workbench 内运行完整官方 Ubuntu Studio，并独立管理版本和档案。本次不连接设备，不进行真实标定、清错、升级固件或运动。

| 检查 | 结果 |
|---|---|
| Python 软件回归 | 532 项：530 通过，2 跳过 |
| 原版来源 | 官方 2026.9.22 `.deb`，SHA-256 与发布资产一致；程序 ELF 哈希复核一致 |
| 组件实际安装 | 官方图形依赖、内部传包、Linux 二次校验、版本目录及客户端准备通过 |
| 源码界面 | 无头 Edge/Playwright，1308×864 和 960×680；原版完整窗口、专注显示、缩放、关闭、版本查询通过，无相关控制台错误 |
| 安装版窗口 | 原生 WebView2，1307×864 和 947×644 内容区域；原版画面、缩放、工作台语言/透明度和关闭通过 |
| 会话交接 | 主、子工作区连接均拒绝并发接管；等待控制器锁的连接请求也会重新核对 Studio 占用 |
| 离线模式 | 原版进程位于独立网络命名空间；没有连接真实设备 |
| 数据保留 | 原有 Windows 参数/配对与 Linux 标定摘要保持；不包括正常变化的窗口尺寸记录 |
| 原控制环境 | SDK 与 CLI 仍为 2026.10.12，基础镜像仍为 1.1.0 |

两项跳过分别为 Linux 专用 `flock` 测试，以及未随公开测试夹具分发的历史实机记录。它们未计为通过。

发现并修复：WSL 不挂载 Windows 磁盘时安装包暂存位置不可达，改用现有内置文件通道；原图形会话与 WSLg 的 X11 路径冲突，改为专属挂载命名空间；关闭画面时重复断开，改为单次清理；GitHub API 限流，改为带明确提示的已核验版本回退；已排队连接可能越过交接检查，增加实际持锁位置复核并以并发测试验收。

Browser 插件未提供，界面测试使用既有 Playwright 库和无头 Edge；安装版使用工作台受限维护 API，仅捕获自身 WebView。没有使用电脑鼠标、键盘或桌面捕获。原版隐私选项保留给用户选择。

未验收：原版真实设备发现与连接、手套标定、触觉 Visualization、固件更新、实机动作，以及跨不同官方版本的真实档案兼容性。程序版本切换不自动降级用户数据，GUI 退出不构成电机停用确认。官方已停止维护 Studio，见 [组件说明](OFFICIAL_STUDIO.md)。
