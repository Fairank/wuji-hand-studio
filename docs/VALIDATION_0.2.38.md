# 0.2.38 验证范围

本版加入官方固件维护和官方稳定 SDK 生命周期。当前官方公开稳定 SDK 经 PyPI 与官方 GitHub 发布记录核对为 2026.10.12。缓存最长 15 分钟，失败不延长时效；每次新会话与新的跟随开始须核对实际控制进程使用的版本，不在跟随中热更新。

## 固件

从设备目录明确选择一台设备，再进入“设备更新”。Windows 使用已校验的原版 CLI 与原版终端，按准确 SN 打开官方升级；实际型号/修订匹配、下载校验、升级计划和最终刷写确认均由官方流程执行。没有 `--yes`、任意文件、全部设备或强刷入口。不猜测未公开的 check/list JSON 协议，不从文本进度生成百分比，不把退出 0 当成实物升级成功。

跨工作区维护占用、终端输入归属、进程退出三态、未知结束、重启恢复、关闭/更新软件门禁均有模拟设备负例。仅对官方固定二进制实际运行了 `--version` 和 `upgrade --help` 的终端兼容性验证，没有扫描、连接或刷写真实设备。固件入口目前适用于 Windows 内置控制配置；其他控制端不提供未经验证的刷写传输。

## SDK

实际控制解释器和 spawned 手套 worker 各自回报 SDK 导入、版本、API 与模块来源证明，通过后才允许打开手套。新的跟随也需有效稳定目录与同一实际 worker 证明；已有跟随的保活不联网查目录。官方 wheel 的来源、SHA-256、大小、路径及完整 RECORD 校验后，内置环境暂存、验证、切换，失败核验原环境回退。个人用户/手型资料与 CLI 不参与 SDK 环境替换。

新接入与标定接续使用官方 SDK RetargetSession，并保留原参数文件。开源调参求解器仅作预览；即使其底层已导入新版 SDK，仍不能冒充 SDK 原生映射启动实机。主机最终派发和实际 worker 分别拒绝非 SDK 求解器的实机准备/跟随。

外部 SSH/用户 Python 仅检查，不静默更改。未来 SDK 新增基础依赖或不再兼容当前 API 时，需要配套工作台适配，软件会明确阻止使用未兼容版本。更新中断恢复按原 token、进程、目录摘要与实际模块核验，不以普通重试解除未知占用。

## 自动版本提醒

后台启动后检查工作台与官方 CLI 公开发布，随后最多每 6 小时核对；CLI 自动入口改为只检查，不再自动下载/切换。SDK 每 14 分钟核对公开稳定目录和选定解释器的纯软件导入，15 分钟目录时效不延长；停止的 WSL/Lima 环境只读列表后推迟，不自动启动。检查失败退避 30 分钟，不进行安装重试。手动维护或控制端改变会使迟到的后台 SDK 结果失效。关闭时停止派发新检查。

同一已接入 SDK handle 单次读取 DeviceInfo，准确 SN 对应后保存固件版本，缺元数据不影响连接。自动固件检查仅针对本次明确连接/标定过的设备，所有工作区空闲并有有效 30 秒设备发现记录时执行准确 SN 的官方 `upgrade --check`，不额外主动扫描。等待 5 秒后，下一个 15 秒后台周期可使用仍有效的记录。官方公开文本表格仅用于提示当前/可用版本，核对型号、准确 SN 与状态一致性，不用于生成刷写计划；无法识别则未知并延后再查，不冒称最新。

已知可用更新统一在现有“⋯”菜单显示数量角标，不占顶栏宽度，点击进入原有更新入口；没有更新时隐藏。中英文及 1040/960/390 三种宽度验证 15 组交互，包含简单模式更新卡本体可见、无自动 POST、陈旧回复、错误与准确设备跳转；提醒前后顶栏四个锚点矩形保持不变。纯后端测试另外覆盖未知报告、型号错配、过期缓存、独立开关、退避、关闭竞态和真实发现 TTL 交叠。

## 验收证据

根回归、独立子代理审计、HTTP 全拦截浏览器交互和中英文窄窗口验证均使用隔离数据与模拟设备。原有停止确认、会话归属、档案接续负例保持。测试、最终包、实际安装与源码同步分别留证，完整记录位于本地 `outputs/firmware-sdk-0238/`。

侧栏针对用户选中换行截图复现：边框改变可用宽度，字重改变使文字跨行，后续导航因此下移。已固定边框盒、字重、图标和文本列，未截字；默认 947 以及 1280/960/1366 四种窗口 × 中英文 × 简单/完整模式共 16 场，选中前后可见项及图标/文字矩形变化不超过 1px，中文单行，英文可完整两行且不越界。

本轮未执行实际 SDK 环境升级、固件刷写、佩戴标定、实物跟随或停用测试。真实硬件效果和完整固件升级/重启后版本仍需用户接回设备验收，不能由模拟测试替代。
