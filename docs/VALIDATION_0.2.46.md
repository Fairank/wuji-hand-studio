# 0.2.46 原生 CLI 独立更新

用户指出 Windows CLI 仍被限制为随工作台软件更新，无法选择自动更新。本轮将原生 CLI 的检查、更新、自动更新偏好、空闲切换与回退作为独立任务，复用现有官方发布资源下载、校验与归档组件。官方自更新会同步全局 Skills，且没有指定安装目录或禁止 Skills 安装的选项，因此不在工作台内直接调用该命令。

工作台、遥操作 SDK 和固件各保留各自版本与流程。CLI 更新不得自动连接设备、启动标定、驱动电机或刷写固件；用户标定库不因软件组件更换而重建。新版本先核对实际软件能力与文件来源，再在所有工作区空闲时切换；进行中的任务继续使用其原组件。

关闭自动更新不再激活正在下载的自动任务；手动更新独立完成。下载前及激活前分别核对所有工作区空闲、控制端选择和维护归属；失败保留原版本。回退后保留对该新版的自动更新暂停记录，避免立即重新升级。官方标定记录按其原始 CLI 版本和文件身份核对，不能因当前组件升级被误判失效。

首次候选包在隔离真实界面点击检查时暴露 GitHub API 限流后备用 HTML 缺少稳定版来源的问题，该候选已撤下，没有安装或发布。修复仅在官方固定 latest 入口经严格校验重定向至同一仓库明确版本后确认稳定版；任意版本页、页面上的 Latest 字样和异常链接均不能代替该来源。修复后已实际从备用入口读到官方 2026.10.26 及准确归档摘要，另有 143 项相关回归和独立 17 项边界检查。

修复后的隔离完整 Python 回归共 1,942 项，失败和错误均为零，2 项按原条件跳过；运行前后 Python 源码未变。另有 246 项原后端专项回归、独立 7 项跨入口和 4 项真实控制器互斥检查，各专项与完整回归重叠，不累加为新增总数。官方 2026.10.26 Windows 原文件完成实际版本、主帮助、查看器帮助和标定帮助检查；这些只证明软件接口，不证明实物标定或跟随质量。真实归档 SHA-256 为 `568148bbdba11c732e699c6f0f87f209c217df523bb01b83d4fe675568889267`。

用户明确要求自行在软件内触发更新，不依赖助手代操作。本次不替换现用安装或 CLI，完整真实下载流程在独立测试数据和端口验证；现用版本仍留给用户自己点击升级。CLI 直接更新无需跳转“软件更新”页面；工作台自身新版仍须存在于其正式发布渠道。

源码、界面失败恢复、最终安装与真实更新分别留证于 `outputs/update-flow-0246`，最终状态以该目录外部交付清单为准。0.2.45已安装的更新窗口、断连清理、设备任务、目标交接和多手控制记录保留在 `outputs/update-flow-0245`，不能将旧结果当作本轮新增 CLI 更新通过。没有进行连接设备、标定动作、实机电机控制或固件刷写；防穿模尚不能作为已交付能力。工作台公开正式安装包发布与本机原生 CLI 独立更新是两个不同的验收范围。
