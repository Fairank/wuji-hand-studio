## 改动与官方能力

默认 Windows 使用固定官方 CLI 2026.10.12。扫描只执行发现，选择不连接。点击「接入并查看」才启动所选设备的官方 Viewer；再次明确点击「切换到标定」才交接本工作区拥有的这一会话。不自动接入，不静默停止其他工作区或别的设备。

客户默认界面读取官方 schema-v2 JSONL 当前动作、稳定性、约束与进度；采集、判断、求解、模型发布仍由原版 CLI/SDK 完成。六个动作与官方 Studio 归档说明一致，不承诺不同版本内部算法逐字相同。六张官方参考图按固定来源及摘要缓存在用户目录，不随源码或安装器分发，不镜像或重画；加载失败显示文字及官方链接。参考图不是设备实测姿势。原版 Human TTY 作为高级选项保留，同一时刻只运行一种标定。

佩戴者与模型状态只读本地官方用户库。交接前核对命名佩戴者、侧别及覆盖意图；仅执行用户明确提交的创建/切换意图，且在自己Viewer清理与全部会话闲置后执行。内部worker再查当前用户、已有模型、严格左右手与精确SN。JSONL不带原版交互提示，必要的佩戴者及覆盖确认只执行一次。

## 状态与生命周期

- 运行状态优先，不因30秒发现记录过期、自己的租约或后台刷新重新变成「正在核对」。已结束的旧输出明确为上次记录。
- 交接核对Viewer token、SN、PID/启动身份、Job及CLI原始设备报告。停止等待不持全局文件锁，确认进程与中继释放后才采集。其他工作区抢占、取消或清理未知均阻止新任务。
- 图形机器流使用原始PIPE及专属隐藏控制台，不经ConPTY渲染。独立合成测试发现ConPTY会加入终端控制序列，原失败证据保留。高级原版终端继续使用现成ConPTY/xterm。
- 完成必须有官方成功result、预期用户和左右手/URDF、实际退出0及Job清理确认。日志字样、旧模型、启动或未知退出均不算成功，失败不自动重试。
- 日志进入详情。标定占用和设备数据新鲜度分别呈现，不把占用写成实时流在线。
