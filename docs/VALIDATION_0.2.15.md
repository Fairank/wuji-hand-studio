本版只改变界面表现，停止、连接、动作发送、映射和标定接口未改。Windows 原位安装的最终结果与校验值见 [发布页](https://github.com/Fairank/wuji-hand-studio/releases/tag/v0.2.15-windows)。

- 485 项现有 Python 检查：483 通过、2 项已有条件跳过；新界面脚本通过语法检查。
- Opus 5.5 max 实际完成离线纯函数模块；8 项曲线/格式检查通过，主助手独立 RK4 积分与闭式曲线最大误差约 4.2e-14，生成结果 `--check` 一致。曲线相对超调 3.95%，对应按钮从 97% 释放后的尺寸超调约 0.12%。
- 本地 8811 独立预览服务验证中英文、明暗主题、设置预览、文字弹窗、节目单与连接浮层。原有焦点返回和 Esc 关闭正常，未出现控制台错误或页面水平溢出。

- 勾选“减少动态效果”后，预览禁用、缩放清除、弹窗动画为 none；取消勾选后恢复。系统偏好遵循代码已审查，本轮没有改用户系统设置作测试。

- 原生软件通过专用维护接口检查正常/窄窗口、已安装资产与源文件一致性；最终结果放在发布页，避免将预览测试写成实机验收。

没有使用实体手套或机械手，没有运行设备动作。未在 macOS/Linux 原生窗口验证本轮动效，也不承诺固定帧率。静态截图仅用于布局证据，回弹时序由渲染样式和交互验证。
