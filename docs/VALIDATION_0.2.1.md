# Windows 0.2.1 验证记录

2026-09-23。本记录只覆盖 Windows 软件、离线界面与构建安装；未连接机械手、手套，也未在 Mac 上运行。

## 发现与修复

| 发现 | 处理 | 复核 |
| --- | --- | --- |
| 空的手指舞节目单占据动作页首屏，主要动作控件需要向下翻找 | 节目单默认折叠为摘要，点按展开；播放时自动展开并显示进度 | 1280×900 和 850×900 的动作页截图显示主要控件在首屏 |
| 内容卡片过度使用半透明材质，黑色主题文字层级不清 | 通透效果集中于导航；内容卡片改为实色，统一边框、文字对比和控件焦点 | 两种宽度的设置、动作、多手设备、手套页面截图检查通过 |
| 旧 Windows 安装包和旧 WujiStudio Windows 压缩包容易与最新版混淆 | 新版原位覆盖旧安装，清除本地 `dist` 中的旧 Windows 包 | 系统卸载项只剩 Hand Workbench 0.2.1，桌面和开始菜单各一个中文入口；官方 Wuji CLI 保留 |

设计参照 [Apple iOS 27 对可读性、均匀折射和对比度的说明](https://www.apple.com/os/ios/) 与 [Apple 人机界面材料规范](https://developer.apple.com/design/human-interface-guidelines/materials/)。Windows 版采用 WebView2 与 Windows 自有窗口材质；不声称调用苹果原生 Liquid Glass，也不声称本版实现外部桌面内容的实时折射。
