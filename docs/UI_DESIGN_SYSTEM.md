# 工作台界面规范

本规范落实用户多次提出的全软件一致、成熟、简洁和流畅要求，适用于设备、灵巧手展示、遥操作、官方标定和设置。不是只调整侧栏或增加装饰。

## 共用样式

- 外层原生磨砂，内容区清晰；保留原品牌与线性图标，不用新手形插画装饰功能页。
- 主文字 `#202126`、次文字 `#676b73`，操作蓝 `#007aff`；暗色以同一语义变量映射，错误与成功仍有文字意义。
- 页面标题25–28px，主内容14px，必要次说明12–13px；官方当前动作28px。间距12/16/24/32px，普通控件36–40px，10px圆角。
- 边框与阴影保持克制。选择、表单、主要操作和异常有明确层级，不重复嵌套圆角卡片或常态徽章。
- 正常就绪不写“准备就绪、由你点击开始”等重复说明。错误、前置条件、停用待核对等原因不能为简洁而隐藏。高级信息收进原生详情。

## 页面与流程

设备列表优先使用宽度；历史以原生折叠区保留。扫描只发现、选择不连接，显式操作语义不变。

单手选择动作后可直接看到预览操作；速度和循环在原有控件中继续可用。多手控制和键盘顺序先于辅助画面，窄屏按同一顺序自然滚动，不能用CSS视觉顺序掩盖相反的键盘顺序。

标定以一张官方静态参考图、当前动作、短指令、真实反馈与真实进度构成主画面；静态图不冒充实时骨架。准备只留必要档案与覆盖确认，成功切到结果，异常与清理待核对保持当前可见。官方终端是同一任务的高级显示方式，不另开一套标定。当前会话与历史记录按精确run ID区分。

## 动效与可访问性

分段和侧栏使用同一选中面，约280ms连续平移与尺寸变化。列表重建或跨页重挂不能重置正在运行的选择动效。页面主体仅短淡入，标题可小幅移动；不在渲染器祖先设置transform/filter/backdrop来破坏浮窗坐标。

反馈不能延迟实际按钮事件或设备请求。禁用控件不播放按压效果，减少动态效果和高对比度下使用静态反馈。键盘焦点、确认范围、原生详情和终端键盘事件维持原语义。

设计概念仅说明布局、层级与样式；概念中示意手图和虚构SN不进入软件。实现继续使用官方资产、实际数据和现有控件，不为追求图像相似而添加假状态、假指标或改变设备门禁。
