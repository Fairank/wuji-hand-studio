# 0.2.29 官方 CLI 工作区与软件更新验证记录

更新：2026-10-22。本记录冻结本版已完成的软件检查及其证据，区分后续构建安装与实机验收；不把源码实现、合成界面或进程退出当作设备功能通过。实际打包、安装、包摘要、源码推送和发布结果由主助手记入外部最终交付清单，不要求修改随包文档再构建一次。

## 本版实现范围

- 原版 Viewer 与手套标定合并为一个顶层「官方 CLI」工作区，单一共享设备选择，明确「查看画面 / 准备标定 / 开始标定」。保留旧标定路由、草稿、会话及取消入口；不增加第二排任务分页，不自动启动、停止或换连设备。
- 默认 Windows 发现、Viewer、用户管理与标定共用固定原生 CLI 2026.10.12和 Windows SDK 用户库。原 Linux 用户不静默迁移；现有 WSL 手套预览、映射及遥操作仍用其自身用户库，不宣称模型已经同步。显式旧 Linux/custom 配置按兼容路径分别处理。
- 标定保留 Default/命名用户、左右手、精确设备身份、已有模型与覆盖同意预检。复用 pywinpty 3.1.0、xterm.js 5.5.0和 fit 0.10.0承载完整官方彩色终端指导；终端内容不由工作台自画姿势或模拟进度替换。
- 启动核对不称采集，TTY运行中的用户只称启动时档案，终端内实际选择为准。退出码0仅记 `session_ended`；取消、停止或会话结束均不自动升级为 `completed`。本次保存需看官方结果并刷新 SDK 模型；旧模型存在不能独立证明重新标定成功。
- 上次宿主退出后如需清理核对，保留明确的结束/核对按钮，即使 `run.running=false` 也可处理；未核对时不允许开始其他设备任务。关闭渲染画面与停止后台会话分开。
- 原生 CLI 发布 ZIP 离线随安装包提供，默认 Windows CLI 随软件配套更新；不再把另一份 Linux binary 的更新冒充当前原生 CLI 更新。不安装或恢复已取消的 Studio。
- 新增设置内软件更新卡与固定仓库 `Fairank/wuji-hand-studio` 的发布检查、下载准备及安装交接框架。安装版启动检查发布版本；下载、重启安装分别由用户明确选择，安装前仍核对全部相关会话闲置。
- 安装包只接受稳定且高于当前的 `vX.Y.Z`、精确 Windows x64 setup 名称及受信任 GitHub 来源，按资产 SHA-256 或该发布唯一同名 `.sha256` 验证，失败不变更当前/上一版记录。暂存有大小、时限、取消与文件系统重定向检查。
