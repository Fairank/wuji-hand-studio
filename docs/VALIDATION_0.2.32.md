0.2.32将官方 `user list/show` 只读本地用户文件与设备会话分开。查询不发现、不连接、不设置数据流，可在设备扫描运行时读取资料。运行环境正在安装、软件正在关闭等本地软件门禁保留；创建/切换用户、启动Viewer、交接和实际标定的全闲置、精确归属、侧别和覆盖门禁不放松。
