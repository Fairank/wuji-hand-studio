# 0.2.67 验证范围

本次入口为统一设备用途切换。连接继续由现有 `ConnectionSwitch`、`GloveBridge` 和官方 SDK/CLI 适配器执行；未新增连接管理器。人员、标定 ZIP、模型及连接设置不因失败或清理诊断退休而修改。

已在隔离资料和设备替身中复现两处缺陷：已存标定仍在正常启动、SDK 导入及回调读回时，局部 12 秒等待先于 45 秒总预算失败；失败后的准确新 SDK 完成退出，但历史清理诊断仍按旧来源归属，继续阻止扫描。

永久回归覆盖超过 12 秒且在总预算内完成、45 秒总预算耗尽、取消与晚回调、原有其他连接预算，以及准确同会话完整退出、错任务和错会话、缺 ACK、读取线程未退出、传输未关闭、跟随和硬件状态未知。旧回归中无所属会话的人工清理字段改为准确已退出会话的证明，不放宽原断言。

流程验证使用真实 Handler、Controller、Switch、Bridge 和 worker，隔离官方 SDK、设备、CLI 与进程边界：导入失败→延迟退出确认→重新扫描→明确接入→官方画面→SDK→主动断开；另检查加载进行中的成功、取消和总预算失败。原始失败和修正后记录分别保留，由非作者使用不同顺序复核。

设备目录的连接操作保留当前页面；准确设备已经连接后，明确选择查看才进入相应页面。相关页面验证包括手套和灵巧手连接、等待时切往设置、迟到回复、明确查看/标定/遥操作和断开。导航意图只影响前端页面，不新增后台连接管理器或自动跟随。

全量软件回归、编译模块一致性、已安装载荷和版本、用户资料保留及现有源码分支同步结果另记于本机交付记录。此文件不代表安装包已公开发布；合成流程不代表真实设备稳定性、物理跟随或固件写入已验收。
