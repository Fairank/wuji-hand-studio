# Windows 0.2.3 玻璃效果验证记录

## 本轮已验证

- 实验折射的四条边缘继续只在用户开启后采集。图像留在本机内存，不保存或上传；重启默认关闭。用户降低系统透明度时关闭该效果。
- 合成图片的浏览器验证：第二次相同尺寸绘制使用一次纹理内容更新，不再重复分配纹理；WebGL 画布尺寸不变时不重新设置。合成顶边外侧 alpha 为 198/255，内侧为 0，背景能透过渐变。
- 设置页在 1280×720 和 850×720 检查；主滑杆和高级调节可以操作，窄窗口无横向溢出；深色模式可读。偏好重新加载后保留，真实屏幕采集开关未被持久化。
- 1080p 的随机图像在本机合成基准下，四条边缘编码中位约 2.7ms、数据约 243KiB/帧；4K 合成基准中位约 4.3ms、约 361KiB/帧。随机图像不代表真实桌面压缩率，也不能推导真实界面帧率。
- `test_external_refraction` 的三项边缘裁剪测试与 JavaScript 语法检查通过。离线生成图测试没有采集桌面。
- 完整程序测试 378 项：377 通过、1 跳过。Windows 打包程序自检、安装器构建均成功；在当前用户账户原位更新后，已安装版本为 0.2.3，安装的折射脚本 SHA-256 与源码相同，临时测试页面不在包内。重启后的工作台可访问、无前端错误，机械手未连接，折射默认关闭。

## 仍需现场核对

- 用户实际桌面移动窗口、滚动其他页面时的帧率与主观流畅度尚未测量；本轮只减少明确的重复分配开销，尚未替换 JPEG/base64/WebView 桥接链路。
- WebView2 的近窗背景折射是非官方近似效果，与苹果系统级 Liquid Glass 不相同；透明度、色彩和混合效果会随 Windows 版本、显示器色彩设置和驱动变化。
- 本轮没有连接真实灵巧手，不涉及电机、控制频率或力矩调整。
