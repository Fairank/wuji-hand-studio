# 0.2.28 滚动区域验证

本版仅调整已有浏览器原生滚动条样式及版本文档。设备发现、人工选择连接、断开、标定协议与控制参数沿用0.2.27，不新增终端控制或设备操作。

## 验证范围

采用已安装的headless Edge与Playwright，全HTTP和设备状态均为合成。Browser插件不可用；特意移除headless默认的hide-scrollbars启动参数，避免隐藏滚动条的截图冒充视觉验收。重点为947×644 CSS视口、1.75设备缩放，并检查明暗、中英及窄窗口。

主面板仍由page-area滚动，弹窗仍由hws-body滚动，不添加新滚动层或自制JavaScript滚动条。核对轨道内缩、槽宽、滚轮与键盘行为、触屏、内容可达性及选中平移。最终结果、截图、构建及安装前后记录在工作区外部 outputs/scrollbar-0228/，不把未运行项目写成通过。

独立验收14组均有通过证据：947×644下标定待机与长运行、设备长列表、设置长页及24项节目单弹窗的明暗主题，原生触屏滑动，1320英文与390中英边界。主轨道上下20px，左右槽各12px；175%截图实测顶端留白24.86px、滚到底后底端25.29px，包含滑块透明边。滚轮和PageDown确实改变原滚动容器，文档不多出第二条桌面滚动条；节目单底部操作区不随内部滚动移动。0页面异常、0意外外部请求，最终CSS摘要在测试前后一致。

首次脚本的运行态刷新禁用、节目单行定位、入场动画小数坐标及外层裁剪高度假设错误均保留原记录，修正测试隔离和原生容器判据后定点复查；未为制造通过而修改业务或移除禁用条件。两张947明暗设计图属于14组的子集，不重复累计。

已有功能的977项Python软件回归见[0.2.27验证](VALIDATION_0.2.27.md)，975通过、2原环境跳过；本次不将相同回归重复累计为新增功能测试。真实标定及多设备效果仍待重新连接后验收。
