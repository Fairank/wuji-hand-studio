# 0.2.73 验证范围

本轮按入口、共享状态及异步先后顺序再次模拟审查，保留原失败、最小修复和不同作者复查证据。现有总回归不代替这些原失败流程。

- 真实 Handler、Controller、连接协调器及 SDK worker 替身：读取目录时来源过期、换会话、操作代次变化、设备退出、未知配对和取消；明确重试沿原准确路由退出后接入，保留两人双侧资料。没有第二套连接状态或自动接入。
- 真实固件目录、包校验、升级服务与读回边界替身：准确成功回执、错设备、错资源、值与原始 JSON 矛盾、失败及迟到旧目录；下一版仍可正常提醒，不把版本事实当升级许可。
- 真实完整页面和诊断 HTTP 处理器：显示 A 时 B 完成、三种导出格式、启动新诊断、失效链接拒绝、重新读取后精确导出；原报告内容及文件名不改。
- 完整页面的预览请求中换页、离线、服务更换和旧回复；页面不被拉回，重复请求受控。采集摘要保存失败、显式重试、磁盘保存失败后的精确内存导出及新服务旧报告缺失均保留准确状态。
- 关闭流程与版本检查的进程替身：整体退出超时后明确继续使用、取消确认失败、旧监控晚醒和真实退出语义；不修改自动更新偏好，不在不明释放状态自动重启维护。
- 原样式、布局、图标、导航和功能入口与上一已验证源码逐项对照。安装后核对原生窗口实际样式、入口、版本及载荷；配置标定资料前后核对。

所有设备、SDK/CLI、升级写入和图形物理边界均使用合成或替身；不连接、练习或驱动实物，不下载真实固件或运行 MuJoCo 物理。实际硬件稳定性、端到端延迟和真实升级未在本轮验收。已知原生诊断截图接口超时保留，不冒称截图成功。
