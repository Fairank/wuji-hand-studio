- 页面内能扫描手套，设备过期需重新发现；未知左右手由用户选择并由SDK实际核对，不猜设备身份。
- 官方动作、稳定性、约束、进度与成功保存必须来自真实CLI事件；启动程序不算已经采集。
- 最新扫描要求取代旧开关：没有接入时每5秒自动查找，真实接入后暂停；「添加设备」重新开始查找。发现设备不自动连接，需选择具体设备并明确连接；旧自动连接偏好不再执行。断开仍通过原会话按钮及停止确认流程。
- 扫描状态与全软件控件统一，删除扫描开关；确认与多选保留勾选语义，禁用状态保持可读，运行状态有明确反馈；键盘、减少动态和系统高对比度仍可用。
- 设备分类、播放目的地、画面来源、字符及关节单选使用同一连续平移背景；中途改选从当前位置继续，文字完整包住，不叠两层选中框。
- 原「空窗口」说明为「无设备查看器」，默认突出实时设备，不取消用户要求的无设备打开能力。
- 同时复验发现、用户、Viewer、标定、预览、映射和多手的软件契约；实机效果留待重新连接后验收。

## 下一阶段：多设备任务标签与独立分区（本轮标定完成后）

用户于2026-10-21新增，明确要求先完成当前修复，再做本节。当前0.2.27不把它写成已实现。

- 没接设备时，不在顶部摆放 Hand/Glove 空状态标签；设备从主页发现、选择、连接后才进入任务标签。
- 标签以正在做的任务为主，显示对应设备、状态及该任务的播放/暂停/停止等常用操作。
- 支持两只手成组演示舞蹈，同时另一只手用于手套遥操作；任务之间保持各自设备归属与控制状态。
- 手套和配对的灵巧手作为固定组合，不拆成难以关联的两个标签；能看清具体是哪一只手。
- 标签可如浏览器标签拖出为专属管理窗口或分区，继续共用同一工作台后台、设备会话与数据；不是另外安装一个软件。
- 拖出、合并、切换标签不自动断开、停止或重新使能设备。任务操作只作用于明确所属设备，关闭窗口与停止设备必须区分并有实际结果确认。
- 先设计设备归属、任务卡与独立窗口流程，再做实现和跨任务回归；不得把多窗口布局完成当作多设备实机并行验收。

## 必须保留的既有方向

### 一个软件与界面

- 名称“灵巧手工作台 / Hand Workbench”，官方 logo，一个安装身份，不再另做多套 Studio 或左手控制台。
- Windows 优先；Ubuntu 与 macOS 兼容/安装按各自系统真实构建、验证，不用 Windows 测试代替其它平台。
- 中英文、明暗、设置分类、清楚的连接入口；磨砂、布局、滑动选中和有阻尼的过渡，尊重减少动态偏好。
- 全流程布局与任务顺序统一，包括连接、校准、映射、多手；不只做侧栏或表面颜色。
- 通过代码、CLI 和工作台自身的有限接口检视、升级，不操控用户桌面。

### 设备、手套与官方组件

- 自动识别设备代际、左右手、编号；支持 Hand 1 / Hand 2，左右手与左右手套。发现、连接、数据新鲜、完成标定分别显示。
- 多设备可以选择已有/新工作区，也可以同一工作区成组使用；不改连先出现的另一台。
- Windows / macOS 的控制依赖应尽量由软件准备，自动网络识别与恢复，减少额外配置；不假称尚需 Linux 的接口已原生可用。
- 当前采用官方 CLI / SDK，取消 Studio 安装方向；CLI 已提供的可视化、标定、诊断与日志直接复用，避免另造一套。
- 官方组件来源可追踪、版本/摘要核对、空闲切换、可回退；不把组件安装成功当作设备或标定成功，不自动升级固件。
- 官方 Viewer 可不接设备打开空窗口；真实数据入口明确选择设备，画面存在不能代替新帧证明。

### 展示、反馈与交互

- 文字输入按顺序播放字母；数字采用用户指定的中国手势，特别6/7/8/9和4的拇指；字母来源与近似范围如实标注。
- 更多手指舞与更充分的运动幅度、侧摆展示；时钟按当前小时和分钟；动作与来源清楚。
- 节目单多选、逐条速度/重复、顺序或乱序、循环；不是只加快播放而忽略轨迹连续性。
- 单手、多手同步、双手衔接动作（如连续波浪）；速度、幅度与参与设备明确可选。
- MuJoCo 跟随真实反馈，标明参考/预览/实测；可调整视角、拖拽浮窗、独立小窗，显示关节编号与反馈率。
- Kp/Kd、发送频率、速度、电流等可编辑并解释；实测值与设定值分开，不把电流A当接触力N。
- 触碰识别、轻扣、撤力释放是独立训练及实机验收项；模型识别、规则响应、已学习动作不能混标。

### 校准、映射与报告

- 官方校准流程、用户档案及保存状态直接使用 CLI/SDK；用户稍后才配合实机标定，不自行启动。
- 映射使用清楚的多行多列参数格，关节位置参考/电机对应；保存、应用请求、新帧生效分开，不能只导出未接求解器就说已生效。
- 手套原始数据、手型校准、重定向输出和灵巧手实际反馈分清；配置按设备、左右手与用户关联。
- 官方 Doctor 与日志支持包、故障Markdown/原始证据可导出。官方错误码与原始报告不篡改。
- 回归、异常退出、断线、重连、多工作区、占用冲突、最小化与恢复、打包安装均需证据；真实动作/映射/标定需后续实机单独验收。
