# 0.2.49 设备发现与维护验证

本轮针对每5秒发现与显式连接的边界、断开后的后台设备查询、固件维护与扫描竞争进行修复。用户要求通过代码操作，直接在本机更新后同步源码，不发布或上传新的安装包。

## 软件流程

- 后台版本提醒消费已采样的 SDK 句柄版本，以及显式固件检查或恢复取得的准确设备结果。发现记录与历史连接本身不会启动固件查询，不把未知版本当成最新。
- 目录每5秒发现，由用户点击连接。设备卡片选择、分类筛选、页面导航和断开后的状态刷新不启动设备连接。
- 设备更新弹层打开、检查请求在途、升级忙碌或退出待核对时暂停发现。关闭空闲弹层后恢复发现；请求未结束就关闭时继续暂停。
- 显式维护请求先让本机只读扫描让出占用，再运行准确设备的检查。取消只作用于固定 `--json devices` 子进程；退出未确认时保留扫描占用，不结束 Viewer、标定或固件写入。
- 维护检查成功与失败都释放正常占用；空闲后可以重新发现，不自动连接。手套 SDK 扫描不再通过工厂地址临时打开设备。

自动化测试使用隔离资料目录、合成设备、受控外部接口与无界面浏览器。界面和服务链由独立审计分别复查；原生构建自检、同 GUID 本机安装及安装后身份核验记录在本轮外部交付清单。源码版本不等于已公开发布安装包。

本轮隔离全量回归为2088项，0失败、0错误、2项环境跳过。另有13项发现生命周期检查、14阶段页面与维护弹层检查、8项独立服务链检查通过。后者包含扫描让出准确设备固件检查、失败释放、未知退出保持占用，以及后台完成后关闭的弹层无需重新打开即可恢复发现。Windows构建自检返回0.2.49、20关节、58动作、TLS检查通过且未连接设备。

## 实物边界

本轮不连接手套或灵巧手，不刷写固件，不开启电机或遥操作。用户将稍后接入设备。软件流程检查不能代替真实设备的标定、固件刷写与实机动作验收。
