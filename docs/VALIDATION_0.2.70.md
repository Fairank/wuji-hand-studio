# 0.2.70 验证范围

本轮只读现场记录显示：SDK 会话仍在接收状态，已确认右侧，但数据新鲜度为过期；后端目录保留正确身份，前端过滤原行后补出的会话卡却没有侧别。修复保留准确当前 SDK/官方查看会话的已知身份，不将数据过期等同于身份丢失。未连接的官方广播不提供手套侧别，界面不从序列号、USB 口或历史推断实际侧别。

用户明确重新接入时，数据过期的同用途会话不再被当成已完成而空转。仅准确匹配当前设备、人员、型号和配置的保存来源可沿用原资料转交路径；预核对失败保留原会话，退出失败不打开新会话，资料和另一侧模型不被覆盖。新鲜会话、查看、读取和普通换页仍复用当前会话，不自动重接。

纯界面刷新新增准确只读 SDK 预览的许可，复用原工作流锁和空闲判断。实机配对、活动或未知停用状态、跟随、维护、其它任务及身份变化仍拒绝；不持控制器锁等待原生窗口回调。关闭和更新的原要求不变，程序二进制更新仍需结束原会话。

各项保留红测，再由实际 Handler、Controller、Bridge 和 worker 的隔离链及实际页面复查正常、帧过期、明确重试、退出拒绝、旧回复与人员变化；异作者用不同顺序复核。全量回归、编译源码匹配、安装后版本和载荷、资料保留及源码同步结果另记于本机交付记录。

本轮设备、SDK、CLI 和网络边界采用替身，不代替真实设备持续稳定性验收。没有自动连接探测左右手、自动确认固件或自动启动实物。纯 UI 刷新保持预览与程序更新需退出会话分别记录，不混淆为任何更新均不中断连接。
