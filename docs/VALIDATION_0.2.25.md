# 0.2.25 验证范围

本页记录统一设备发现与选择的验证边界。最终冻结源码的 958 项 Python 回归中，956 项通过、2 项跳过；安装与发布单独记录。

## 本轮改动

- 统一展示已观察到的机械手与手套，按实际编号选择，区分发现、占用、连接与反馈状态。
- 设备页可见且允许时自动发现，保留手动重新查找；选中设备不会自动打开数据流、标定或动作。
- 官方画面、SDK 预览与标定使用一致的选择；保留明确的会话交接及退出确认。
- 标定页消费共享设备缓存，用户元数据刷新不再重复发现；受阻时保留历史档案并标明未核对。
- 扫描开始和失败清除该次扫描的可选结果，Viewer 启动要求近期成功发现及准确编号。
- 指定机械手编号时，在有限窗口内等待目标，不因另一只设备先出现而改连或立即误报离线。

## 尚未进行的真实设备验收

**本轮没有建立新的真实 SDK 设备连接、手套数据流或标定。** 多设备、故障及控制工作流验收使用明确隔离的假接口或合成数据，不沿用旧版设备连接结果宣称本版已通过。

CLI 程序运行、端口可连或画面载入不能证明反馈持续在线；设备编号规则不能替代设备身份核对；软件测试不能证明真实标定、识别或自主轻扣已经完成。
