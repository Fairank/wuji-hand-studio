# 0.2.52 完整流程与异常恢复复查

本轮继续检查启动、设备选择与切换、发现占用、子工作区关闭、模型导入、组件替换、参数、录制及导出相关流程。只使用代码操作；设备、进程和组件替身隔离于现用资料。以下问题均先复现再修复。

| 流程 | 原问题 | 修复与复查 |
| --- | --- | --- |
| 窗口启动 | 保存的JSON为数组、空值等非对象时启动异常；浮点端口可能传入服务 | 验证对象和整数端口，异常回退；原配置不被检查过程覆盖 |
| 选择设备 | 等待目录刷新时可改选，旧操作随后强行选回旧设备 | 等待期间禁用单选，后续再次确认序列号；外部改选时取消旧操作、保留新选择 |
| 离线目录 | 离线事件后在途旧200响应重新启用设备入口 | 用服务代次拒绝旧响应，只有新的有效刷新才能恢复 |
| 发现退出 | close异常被误当已清理；false结果丢失原退出对象、无法重试 | 保留原拥有对象、查找标记和清理状态；显式结束只重试原任务，确认释放后恢复入口 |
| 子工作区退出 | kill后未确认退出即清空记录 | 有限等待并再次核验；失败保留记录、阻止关闭，重试期间拒绝新增工作区 |
| 模型导入 | NaN或可广播错误形状可能通过误差检查 | 精确形状、浮点类型及有限值校验，拒绝缺失/额外/重复数组；保持1e-4门槛，失败保留原模型 |
| 内置运行时替换 | 原环境或CLI已移到备份但中断，当前组件缺失 | 重命名前记录意图，分别恢复两个原件；一项恢复失败不阻止另一项，保留恢复文件 |
| SDK替换 | 同型中断后环境缺失，直到后续恢复 | 立即恢复原环境并核验原证明，记录rolled_back；未知恢复状态继续保护 |
