# 0.2.47 任务、尺寸与恢复验证

0.2.46正式发布后，继续逐项核对用户此前的交互与功能要求。此版本源码在独立工作区修复，不替换已审计的0.2.46安装包；用户自己在软件里触发更新，助手不代为安装或升级现用CLI。

单手任务的暂停、继续和停止分别处理。暂停保留播放进度及当前控制租约，继续不重新开始动作；心跳或反馈失联仍停用设备。播放列表段间边界与暂停操作共用归属检查，暂停期间不得偷偷开始下一段。同一设备的新动作有新的运行身份，旧标签不能暂停或恢复新一轮动作；多手编组继续使用原有共同时间轴。

任务标签支持内部排序和拖出为独立窗口。取消、指针取消和弹窗拦截保留原视图，浏览器弹窗跨任务交接只有在核对准确权威回执后才迁移登记；关闭窗口仍只关闭视图。暂停后的停止入口与当前状态保持一致。

CLI画面高度调整同步终端行数。初始终端仍按38行启动，用户调整可在12–100行及81–240列内变化；连续拖动合并相邻尺寸请求，键盘输入顺序保持。窗口切换或尺寸变化不重新开始标定或替换会话身份。

固件异常恢复的同一设备实际读回版本更新当前版本、检查时间和提醒；新的原始检查报告需再核对序列号、设备类型和版本。没有新目录时只确认实际版本，不能把旧预检重新盖上时间戳或称已是最新。身份或版本矛盾继续保留待核验状态与原租约，不再次刷写。恢复核对不单凭版本读回就声称本次刷写成功。

映射预览使用官方模型的实际网格与运动学，覆盖四种手型的290对非相邻指段及掌部几何关系。显示姿态须逐帧取得几何分离证明；距离查询不确定时不得当作安全。指段运动上界限制每帧推进，完整证书未获得时不发布新的约束画面。静态几何检查不推进动力学、不运行策略、不向设备发送动作。

默认预览与旧的目标/约束显示入口复用同一几何适配器。实际SDK目标、发送给实机的指令与实测反馈原样保留；真实反馈缺失时不拿生成的姿态冒充实测。现有画面来源标记注明约束显示，不新增“碰撞预演”页签。模型首次载入较慢时保留已核验实例，等待下一帧新数据，不重复销毁和载入；发布前再次核对来源与数据时效。

约束显示仅影响预览，显示几何检查不能作为实物避碰或真实运动质量验收。最终实现、软件回归、界面证据与打包结果以 `outputs/update-flow-0247` 的最终外部交付清单为准。

独立静态几何检查覆盖600帧及2742次半空间可行性核验；四种手型的普通屈伸和接触后张开均能达到原显示目标，交叉目标保持几何约束而不改写SDK数据。12组真实渲染链路及69项针对性合同测试通过。旧动态预演构造器和动力学步进在该渲染验收中被禁止。

最终隔离后台回归为1986项、零失败、零错误、2项跳过：原本机实物记录不随单元夹具分发，Linux文件锁案例不在Windows上执行。中英文30种页面状态通过布局、导航稳定性与脚本错误巡检。来源切换另验证旧请求、解码中切换、独立窗口和多手画面，不能以这30种空设备页面代替已连接设备的交互验证。

真实六动作标定质量、实机切换/跟随/停止、多设备并行及固件刷写仍需真实设备验收；软件替身、静态几何和界面截图分别留证，不混称已经实机通过。
