# 0.2.74 验证范围

本轮以 0.2.73 干净源码及已安装文件为基线，主动构造新的中断和异步先后顺序，保留原失败与不同作者复查。检查不更改原设计及功能范围。

- 目录读取：超时后晚 EOF 与精确关闭确认、线程构造在任何外部访问前失败、旧读取器与后继构造交错、未确认关闭及明确重试；不接纳迟到目录，不自动查询或连接。
- 显示链：主画面与独立窗口原服务帧晚解码、新旧服务并行响应混合、相同设备身份跨服务、新帧恢复；显示映射表单与准确服务、会话、设备及型号绑定，拒绝迟到串写，保留原官方 SDK 目标和相机语义。
- 软件更新：关闭已取消后旧页面或后台请求晚受理、关闭前已受理任务的取消、关闭失败后的明确重试、安装与关闭的锁交错。真实生产函数配合服务、存储和进程替身，不下载或执行真实安装包。
- 参数同步历史：非对象、非法字段、异常编码、目录或访问拒绝、过大与深层嵌套、大小观察后扩大、有界读取、合法记录重启；原参数及历史字节保持。
- 原失败流程重走、相关回归与非作者异序复查分别留证；统一源码回归、构建、原界面资产对照及安装后版本、载荷和资料保留另存外部交付记录。

全程不以真实设备、SDK/CLI 调用、固件写入或 MuJoCo 物理代替模拟验证。实际硬件稳定性、真实升级与端到端延迟未在本轮验收。已知原生诊断截图接口超时保留；原生 DOM/样式检查不冒称截图成功。

显示映射编辑属于现有隐藏兼容表单；本轮验证其原 DOM 回调到实际 HTTP 服务的保存契约，不将它描述为当前普通导航中的可见操作，也不新增入口。
