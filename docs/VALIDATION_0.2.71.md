# 0.2.71 验证范围

本次修复遥操作画面延迟的已复现软件路径，不将合成耗时当成本机硬件延迟实测。

- 真实 PoseView 运行循环及 HTTP 处理函数配合图形、时钟替身：最终状态校验或发布锁等待不能让过期原帧变成实时；准确同源的较新序号不阻止尚有效的画面。缓存按原源数据期限失效，私有时钟不发送给前端。
- 主页面与独立小窗真实 JavaScript：按请求起点计算刷新周期，正常解码、解码挂住、超时恢复、旧解码晚成功或晚失败、换页与设备身份变化均核对。网络、解码和小窗的最终身份确认耗时计入图像原期限，不用较新的 SDK 序号为旧图续期。
- 真实几何推进代码配合合成数组与时钟：已验证准确姿态不再每帧重复核查挤占新姿态预算；模型对象、模型摘要或姿态改变必须重算。新候选完整检查，部分失败恢复最后已证姿态与分隔面；原 290 对覆盖、间距、18 毫秒预算和 SDK 目标保持。
- 非作者使用不同锁等待、候选失败和异步回复顺序交叉检查；源码总回归、构建与安装核验的具体结果留在外部交付记录。配置与标定资料核对保留。
- 安装后曾实际捕获部分原生资源未加载：同源、无重定向、桥接存在，失败资源状态为 0 且无响应数据；基础页面暴露并不代表版本回退。原界面刷新恢复，原始失败和诊断保留。受控 48 个待接入静态请求在原默认队列只有 5 个成功，扩大队列后全部通过，非作者三轮复查通过；普通浏览器冷启动两种队列均正常，因此不将队列脆弱性冒称已确认的现场唯一首因。原 UI 设计资源和功能入口须与修改前版本一致，并另验实际原生窗口。

未运行真实 MuJoCo 物理、真实 SDK 或实物动作来代替软件测试；实物端到端延迟、连接稳定性与独立真实灵巧手展示未在本轮验收。现场只读快照当时无手套会话，无法据此测出用户所见的实际延迟毫秒数。
