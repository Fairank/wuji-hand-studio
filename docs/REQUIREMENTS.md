# 工作台需求与验收清单

2026-09-24，按用户历史要求及最新决定整理。入口存在、代码测试通过、真实设备验收是三种不同状态。以下状态基于当前源码；没有本轮实物验收的条目不会标成全部完成。

## 最新决定

- 唯一软件名：灵巧手工作台 / Hand Workbench。沿用官方来源标识，明确非官方个人工具。
- 0.2.7 删除实验桌面折射实现与设置，使用系统原生磨砂。停止追求自制 Liquid Glass 外部像素变形。
- 中文/英文、白色/黑色/系统主题、清楚的分区和短过渡。控制靠代码维护接口，不接管用户桌面。
- 基础编码可交本地 Claude，主维护者审核。0.2.8 已确认本地 Claude 登录有效，两项基础模块返回 `claude-opus-5-5 --effort max` 并完成审核；0.2.7 未调用的历史记录保留。

## 功能范围

| 用户要求 | 当前实现 | 剩余验收或缺口 |
|---|---|---|
| 一个软件、一个图标、一个安装入口 | 统一 Hand Workbench；升级沿用用户数据 | 不增设研究版或 Studio 主程序 |
| Windows、macOS、Ubuntu，统一模板 | 共用前端及控制接口；Windows 原生壳；Mac Cocoa 源码；Ubuntu 本地 SDK | Mac 新包、真实设备和内置 Linux 启动仍待；Ubuntu 新版打包仍待 |
| 内置小 Linux，不手动管理大虚拟机 | Windows WSL 控制包；Mac Lima/ARM 镜像准备流程 | 平台网络、USB 转接仍有边界，不等于原生 Windows/Mac SDK 控制 |
| 黑白/系统、中英文、简约磨砂、减少动画 | 0.2.7 设置统一管理；顶栏/目录和内容区分别滚动 | Windows 外观实测记录另列；Mac 视觉未验收 |
| 右上角随时连接、看手与手套状态 | 手连接/断开、候选设备选择；手套状态及遥操作/映射直达 | 手套连接操作在专页；不自动中断另一条设备会话 |
| 更换任意手后自动识别 | 二代左右官方地址重新发现，读取设备身份；多候选选择 | 未知自定义网段、所有硬件代际、USB 自动接入不能保证全覆盖 |
| 一代/二代、左右、多手同时工作 | 四套原生模型、独立工作区和进程；序列号互斥、独立保活、总览停止 | 一代编排仍为官方张开/握拳，新增 LowPass 手套跟随；所有多手同时动作组合未实测 |
| 手套自动连接、遥操作 | 手套扫描、预览、序列号配对、准备手反馈、显式跟随；SDK/映射/发送/反馈分列 | 官方 retarget 后端走 Linux；一代跟随和跨平台实物仍待 |
| Wuji Studio 风格的可视化与标定 | 独立21点骨架/三维手；六姿势参考、命名用户、官方事件/报告、跨工作区互斥与取消传递 | 六姿势实物流程未验收；未知进度不猜，非官方全传感器调试录制 |
| Retargeting 可调 | 官方映射后20关节 gain/offset、平滑；按设备/用户配对隔离、命名预设、预览应用和控制端参数核对 | 不是开放官方 IK 内部全部权重；实机需重连载入，硬件效果逐项验收 |
| 更多手指舞、足够幅度、展示侧摆 | 现有九套编排，含水母/波浪等侧摆轨迹；幅度可选 | 不能称集成官方全部动作；各代左右实机轨迹未逐一验收 |
| 中国数字1–10，4缩拇指、6/7/8/9习惯手势 | 已有对应近似轨迹和来源说明 | 地区变体、不同机械手精度需实物检查 |
| 24字母、输入 wuji tech 顺序执行 | 固定手腕 ASL 近似、文字编排、紧凑选择对话框 | 不是官方或全球通用手语；动态字母/手腕受机械结构限制 |
| 当前时间报数 | 取启动时刻 HH:MM，按四个数字展示 | 当前不是持续读取每分钟变化的报时服务 |
| 手指舞多选、顺序/随机、循环、宽速度范围 | 节目单逐动作速度/次数、整单循环、0.1–4×、暂停/继续/停止 | 0.2.7 保留整单选项，修复反馈刷新打断编辑；倍速不等于力度/电机Hz |
| 实机姿态和 MuJoCo 同步，画面可拖拽调视角 | 反馈/预览来源标识、原生关节模型、浮动/停靠/独立窗口与相机操作 | 同步质量取决于真实设备反馈；不能用预览冒充实机 |

| WujiDoctor、日志、导出、代码维护 | 官方诊断、采集/运行记录、维护API；0.2.7支持设置/多手页导航 | 有设备时仍需独立诊断；维护API不提供任意脚本/电机命令 |
| 戳手后无视觉识别、选择配合指、轻扣/松开/恢复 | 保留私人模型导入及离线识别路径 | 实机自主轻扣未完成，不将规则动作或旧分类分数标成已学会 |
| GitHub公开基础功能、私人模型不公开 | 单程序+本地可选模型包，公开构建排除私有权重/凭据/设备记录 | 源码提交、安装包、实物验收分别记录，不互相代替 |

## 后续优先顺序

1. 手/手套切换及候选设备选择的完整实物链路，包括更换设备和故障恢复。自动发现不能偷偷启动跟随。
2. 多手同时连接与独立节目单、手套和手的明确配对，避免一个工作区占用另一个工作区设备。
3. 各代动作、标定、retargeting的实物结果；一代USB与跟随支持补全。
4. Mac内置环境和新版Ubuntu包实机验证，保持同一模板。
5. 完成反馈标定后单独推进私人识别模型的实机验收；不混入基础展示发布结果。

用户尚未取消的要求均保留。对尚缺硬件、平台或控制实现的条目，继续记录缺口，不能只新增一个按钮就标为完成。
