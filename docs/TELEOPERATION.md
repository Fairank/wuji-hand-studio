## 0.2.43 当前流程

标定结束后在结果区选择「继续使用这只手套」，沿用本次官方档案进入遥操作预览；资料按用户身份、侧别、模型内容核验，冲突保留原数据。实体灵巧手有独立的查找、选择和连接入口，连接后再明确开始实机跟随。扫描与单纯选择不连接，进入任务和切换画面不启动电机。任务标签可双分区、拖放、在软件内浮动和停靠；关闭标签只是关闭视图。解除配对先确认目标反馈已释放，保留当前手套和用户。

# 手套遥操作

侧栏「遥操作」是映射预览和实机跟随的专门工作区。普通页面导航与发现列表选择不连接设备；明确的「切换并连接」会结束原会话、接入所选功能，不会开始实机跟随。

## 操作顺序

1. 选择实际对应的映射型号与左右手。准备遥操作控制端后，选择本控制端实际发现的手套与SDK用户。
2. 如果正在查看官方手套画面，明确「切换到遥操作」。已有有效档案时沿用；需要选择时，在同一处选择实际 SDK 档案。核对目标后结束准确的原 Viewer，确认释放并接入手套。无需再点一次连接，也不启动跟随。
3. 初次使用可直接连接手套并预览；已接入后，可明确切换到官方画面或新的设备。正在运行的原动作先确认停止，退出未确认时保留原因；不会为了切换停止其他独立任务。没有灵巧手也能查看映射目标，这不是实机动作或反馈。
4. 在「实体灵巧手」中点击「查找灵巧手」，选择同侧、同型号的设备，再点击「连接灵巧手」。手套已接入时也能查找后来接上的灵巧手，保留当前手套、用户和标定资料；不会因此重连手套或更换求解器。编号和实际 SDK 身份都要一致，连接只读取反馈，不启用动作。
5. 核对画面与活动空间，勾选本会话确认，再明确开始跟随。断连、换设备、会话改变或失联后，旧勾选不能继续使用。
6. 暂停跟随会沿用原停用与确认流程，不以界面切换冒充设备停止。确认后才能再次明确开始；断开结束当前会话。

主画面自动使用当前可核实的数据，不再提供额外的来源切换栏。未连接实体灵巧手时显示映射预览；已连接的实测反馈缺项或过期时明确显示不可用，绝不改成生成目标冒充实测。暂停、失联后也不自动恢复实机跟随。确认断开后清空本次设备选项，保存的配对设置和标定档案仍留在本机。

预览后再选目标，只允许与当前已应用的映射和求解设置等价的绑定。若该目标有另一套配置，软件保持原绑定不变并提示：断开预览，先选目标，再重开预览核对。不会静默换增益、求解器或动作配置。

## 官方复用与平台

原版CLI的Viewer用于原始数据查看；完整实时跟随复用官方SDK/RetargetSession及已有官方开源求解路径，不把Viewer在线当作遥操作已接通，也不另写一套映射算法。

Windows使用已配置的内置Linux控制端或显式Linux控制电脑。当前官方RetargetSession支持Linux x86_64/aarch64；原生Windows Viewer与Windows标定库不等于这套控制端的SDK用户库。档案列表以实际控制端为准，同名不能证明模型已同步，不静默搬运或覆盖模型。组件缺失、控制端不可用时显示具体准备原因，不留一页无法解释的禁用按钮。

本版一键交接覆盖 Windows 原生官方 Viewer 与已配置的遥操作控制端。自定义或 Linux 官方 Viewer 尚不能提供相同的会话释放证明，因此自动切换会在断开前提示限制并保留原连接；其既有官方入口仍可使用。

型号、地址、失联时限、参数与数据率在详情中查看。实际停止、终止记录、精确设备归属、数据新鲜度及控制租约仍由原控制链核验。软件与合成界面验证不等于实机精度或物理停止已验收。
