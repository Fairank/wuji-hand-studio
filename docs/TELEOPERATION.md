# 手套遥操作

侧栏「遥操作」是映射预览和实机跟随的专门工作区。进入页面、选择设备或切换画面都不会连接设备、使能电机或开始跟随。

## 操作顺序

1. 选择实际对应的映射型号与左右手。准备遥操作控制端后，选择本控制端实际发现的手套与SDK用户。
2. 如果正在查看官方手套画面，明确「切换到遥操作」。仅结束本工作区精确拥有的这一Viewer，确认释放后扫描原控制端；不会替你连接或启动跟随。其他工作区占用或清理不明时不开始。
3. 明确连接手套并预览。没有灵巧手也能查看「映射预览」，这是目标姿态，不是实机动作或反馈。
4. 需要实机跟随时，选择一只同侧、同型号的目标，明确连接其反馈。编号和实际SDK身份都要一致。该操作只读取反馈，不启用动作。
5. 核对画面与活动空间，勾选本会话确认，再明确开始跟随。断连、换设备、会话改变或失联后，旧勾选不能继续使用。
6. 暂停跟随会沿用原停用与确认流程，不以界面切换冒充设备停止。确认后才能再次明确开始；断开结束当前会话。

主画面可选择「映射预览」或「灵巧手反馈」。实测模式缺项或过期时明确显示不可用，绝不自动改成生成目标。暂停、失联后也不自动恢复实机跟随。

预览后再选目标，只允许与当前已应用的映射和求解设置等价的绑定。若该目标有另一套配置，软件保持原绑定不变并提示：断开预览，先选目标，再重开预览核对。不会静默换增益、求解器或动作配置。

## 官方复用与平台

原版CLI的Viewer用于原始数据查看；完整实时跟随复用官方SDK/RetargetSession及已有官方开源求解路径，不把Viewer在线当作遥操作已接通，也不另写一套映射算法。

Windows使用已配置的内置Linux控制端或显式Linux控制电脑。当前官方RetargetSession支持Linux x86_64/aarch64；原生Windows Viewer与Windows标定库不等于这套控制端的SDK用户库。档案列表以实际控制端为准，同名不能证明模型已同步，不静默搬运或覆盖模型。组件缺失、控制端不可用时显示具体准备原因，不留一页无法解释的禁用按钮。

型号、地址、失联时限、参数与数据率在详情中查看。实际停止、终止记录、精确设备归属、数据新鲜度及控制租约仍由原控制链核验。软件与合成界面验证不等于实机精度或物理停止已验收。
