# 手套标定与官方画面

## 重新连接后怎么开始

1. 打开「连接与校准 → 手套校准」，点击「扫描手套」。选择实际手套编号；已发现记录超过30秒需重新扫描，刷新用户状态不会把旧设备变成在线。
2. 创建命名用户，或选择已有用户并明确切换。Default 是官方默认模型用户，官方 CLI 不允许在它下面做手型标定。名称按页面说明填写，创建及切换都必须由你点击确认。
3. 核对左右手。发现信息没有报告侧别时，需要你选择；工作台仍会在启动采集前读取实际设备身份并核对编号、左右手。不用编号猜侧别。
4. 若已有这侧的标定，明确确认是否覆盖；否则保持原模型。页面显示准备完成后，点击「开始标定」，跟随官方当前动作和稳定性提示。
5. 等待官方成功结果和正常退出。取消、异常退出、只收到部分数据或只是画面打开都不算完成。

手套预览、官方画面或另一个工作区正在占用设备时，先在所属会话中停止或断开。页面只提供明确的下一步，不会悄悄结束你的设备会话。标定动作需要实际佩戴手套，本次软件修复没有替你采集动作或保存新用户标定。

## 标定保存到哪里

官方产物按当前 SDK 用户和左右手保存。工作台内置 Linux 控制端的标定由该控制端用户管理，后续手套预览和映射要选择同一个用户。Windows 原生官方 Viewer 使用自己的 SDK 用户环境，不能因为 Linux 标定成功就声称其模型已经自动同步。跨机器迁移使用官方用户导出/导入流程，不能只复制界面上的名字。

已有个人模型时，失败、取消或未确认结果不能显示成新模型保存成功；原始 CLI 结果和错误可在「详细记录」中核对。工作台不另外创造采集姿势、通过阈值或估算进度。

## “无设备查看器”是什么

这是先打开官方 Rerun 查看器，不连接设备，不接收实时手套数据，也不进行标定。它用于检查查看器本身能否打开。日常使用默认进入「实时设备」：查找设备、选择实际编号，再明确启动实时画面。切到无设备查看器不会停止已有设备会话，停止必须单独操作。

## 软件检查与设备验收

测试使用隔离假接口及合成数据，检查准备条件、发现与过期、用户创建/切换、左右手、占用、官方进度、取消及结果判定，并回归映射和多手。真实采集、标定质量、模型效果与断线重连需接设备后单独验收，不能由软件测试代替。
