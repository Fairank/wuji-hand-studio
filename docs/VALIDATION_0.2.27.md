# 0.2.27 标定软件验收

本版修复标定准备、错误反馈与官方可视化入口。用户已断开手套，真实采集与模型效果由重新连接后单独验收；本次不创建用户档案、不启动真实标定、遥操作、电机或触觉清零。

## 已修复

- Default 官方用户禁止标定的限制保留，创建命名用户直接显示。当前用户与待切用户分开；显式创建/切换成功后采用返回确认的用户，未提交的选择仍保留。
- 页内扫描复用共享目录；不再把用户状态刷新当成重新扫描。等待真实后台发现结束才刷新候选，隐藏或切页停止等待，发现记录过期后不能显示可开始。
- 无手套、元数据未知、侧别不匹配、模型状态未知、未确认停用、占用及设备列表错误分别说明并提供下一步。未知侧别需明确选择，启动前原SDK实际身份复核保留。
- 覆盖同意绑定当前用户、待切用户、左右手、精确设备编号及已有模型状态，变更后清除；没有已有模型时请求始终为replace:false。
- 主机在启动进程前拒绝默认用户或未知模型状态；启动阶段不称采集。官方动作、稳定性、约束、保持时间、帧数和进度按真实事件显示；成功result及正常退出共同确认完成。
- 可视化默认实时设备；无设备查看器需明确选择，说明没有数据、不能标定，切换不自动停止已有设备会话。
- 自动查找不再有开关；成功接入后暂停，「添加设备」恢复。旧自动连接设置和偏好执行全部删除，扫描结果必须由用户选择并明确连接。原会话断开入口及停止确认语义保留。
- 新的扫描例外仅用于原生官方广播发现，要求每个已接入灵巧手具有严格的SDK身份、支持的代际左右型号、新鲜反馈且明确未使能；Viewer、标定、升级、手套及其他任务门禁保持。未知/畸形型号和停用未知状态均拒绝。
- 设备分类、播放目的地、画面来源、字符及关节选择复用一个连续平移背景；重建选项保留同一底框，键盘导航不把底框当按钮，减少动态和高对比度回退保留。审计发现的两处旧静态色块已清除。

## 构建与安装核对

沿用同一软件身份和用户数据目录；核对冻结代码对象、界面资源、控制端源码及随包文档与实际安装一致，并比较4项核心配置摘要及语言/外观偏好。不逐文件重审全部私有标定或模型，也不自动迁移Linux与Windows Viewer用户档案。

最终二进制摘要、安装前后回读、截图与子审计证据存放工作区外部目录 `outputs/calibration-0227/`；安装包自身摘要不写进随包文档，避免自引用。源码上传和二进制Release分别确认，不以本机安装代替公开Release。
