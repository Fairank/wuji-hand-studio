# 0.2.78 统一发现、反馈退出与参数同步

本轮针对原生目录遗漏灵巧手、接手网口地址冲突、失效反馈任务阻塞发现，以及参数同步需要手动多次断开和接入的问题。继续使用现有官方 SDK、CLI、用途切换和退出流程，不新增常驻连接管理器，不通过扫描、页面切换或保存参数自动接入设备。

统一发现保留原生与 SDK 来源，原生结果只有手套时也补充 SDK 灵巧手广播；未知左右手不猜测，SDK 专有发现不冒充官方原生查看器支持。取消、配置变化和旧回复不能恢复旧目录。网络面板只读检查物理 Ethernet 和 USB 网口；明确修复按钮才可配置地址，排除所有已占用地址且执行前再次核对。

参数同步绑定当前原手、服务、代次、请求和参数修订。只读原手明确退出后，才保存、传输、核对并重新接入同一原手一次；空闲无设备时仅同步，不接入。电机或跟随运行、未知退出不能自动越过。同步已完成但重新接入失败仍保留同步事实，取消后不继续接入，明确重试不能影响替换后的会话。设备页区分真实连接与失效的当前反馈任务，历史与扫描记录不授权结束任务。

专项验证使用真实控制器、HTTP 处理器与页面代码，配合隔离 JSON 工作端、SDK 和 CLI 替身，覆盖失败、取消、重试、重复点击、旧身份和迟到回复。前后端另由非作者核对实际 DTO 与操作顺序。完整软件检查、编译源码一致性、本机更新、用户资料和全部网页资源核对结果另存于外部交付记录；源码版本不代表这些交付步骤已经完成。

现场曾只读保存设备与主机状态，并经明确操作将实际接手网口配置到独立可用地址，保留无线网络、默认路由和 DNS。该现场修正与离线软件验收分别记录。没有以模拟验证宣称真实标定、固件刷写、实机遥操作或长期连接稳定性通过；此前固件失败的原始详细结果没有保留在当前缓存，不能据此宣称该实物固件故障已修复。原磨砂玻璃样式、导航结构、人员、设置与标定文件保持。
