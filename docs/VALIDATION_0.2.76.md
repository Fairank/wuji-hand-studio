# 0.2.76 标定生命周期复查

本轮继续复查 0.2.75 刚修改的标定结果、缺帧与明确切换流程，在原失败之外构造不同的回复顺序。真实函数与完整现有页面使用隔离的网络、文件、官方 CLI、SDK 和进程替身；没有连接实物或执行真实 SDK、CLI、固件写入及 MuJoCo 物理。

- 新标定已完成但开始前 Viewer 的只读查询尚未更新时，新结果仍留当前区域；真正后继会话再退出、未知或重入时，旧结果继续留在历史。
- 同服务另一窗口发布新的采集或清理运行后，旧资料请求的成功或错误回复不能遮住它。当前取消及清理按钮对应准确运行。本页自己的成功回执也不会被开始前的旧公共状态反向撤销。
- 准确取消已返回、但 SDK 会话编号回执仍被挂起时，迟到就绪事件不再接入或写设置；退出确认后明确重试仅接入一次，沿用同人模型。错误尝试、未派发的取消拒绝、退出未知和正常就绪分别复查。
- 旧帧与退出确认、导出已生成但回执失败、明确重试、再次覆盖标定、换页、同设备再选、人员、终端模式及服务变化按不同顺序复查，失败与更正记录保留。
- 界面设计和功能入口不变，仍沿用统一用途转接和 Bridge 已有最后接入保护，没有新增后台连接管理器、自动重连或宽松身份判断。

一个直接注入“新公共运行后倒退到旧公共运行”的函数反例未找到现有单轮询生产者的可达路径，作为防御性候选保留，未当作用户缺陷扩修。各原失败、修后完整页面检查及非作者异序证据列于外部交付清单。

实物断联首因、硬件稳定性、实际升级及端到端延迟仍未验收。原生诊断截图接口既有超时保留；原生 DOM/样式核验与隔离浏览器截图分别记明，不互相代替。
