# 0.2.60 完整流程与失败恢复复查

从 0.2.59 源码继续检查原有入口和共享实现。本轮分别检查标定、多档案、连接切换、普通展示播放、更新、固件结果解释、采集及导出，再由非作者用不同失败位置和操作顺序复查。软件检查使用真实源函数、完整源页面和隔离替身；测试数量不代表实物已经验收。

## 本轮修正

- 标定接续请求尚未返回，但新状态已经给出准确的任务与尝试编号时，可以直接取消。取消、换档案任务、离线或更换服务后，旧开始回执不能覆盖当前结果或自动跳页。未知编号不发送取消；已经载入的会话继续保留。
- 设备切换在取得状态、读取档案、提交、恢复结果和核对新归属的各个阶段校验同一服务身份。旧服务回复不能覆盖新手套会话，迟到的结束进度不能清掉新租约。离线时关闭属于旧服务的档案选择窗口，释放本地等待状态，不擅自取消设备任务。
- 合法任务操作引起的归属重核与真正的服务断开分别处理。任务页保存配对后的原接入可以凭精确回执继续；启动跟随后，只能由本次正确回执、同一手套与灵巧手身份、当前控制代次建立新租约，旧租约不会恢复。配对读取也绑定控制代次和目标，迟到结果不能覆盖新配对。
- 软件更新离线后立即撤销旧页面状态。旧读取回复不能恢复下载按钮，尚未取得本次有效服务身份的操作不能继续提交；已经发出的安装请求仍按结果未知处理，不能伪装成成功或自动重发。
- 本地 CLI 完整性校验失败时显示待校验与实际原因，记录中的版本号不能被当成已验证的当前版本，也不能显示已是最新版或更新完成。更新选择和用户自动更新偏好保持原样。
- 恢复的诊断报告含异常时间或非有限元数据时，文本、JSON 和支持包导出仍能交付原始输出。公开元数据明确标记未知，原标准输出、错误输出、退出码及保存文件保留；不能据此把诊断失败算作通过。
- 普通预览控制的迟到回复绑定型号选择代次、所在页面与服务状态，避免切换型号后旧失败覆盖当前操作提示。开始、暂停、继续和停止按同一个当前播放编号核对。

## 原问题清单的验收范围

| 原问题 | 软件检查范围 | 实物边界 |
| --- | --- | --- |
| 扫描时自动连接、断开后残留、连接对象错乱 | 只读发现、明确接入、准确序列号与会话、旧响应和重复操作 | 未为检查接入设备 |
| 标定成功后套用失败、多份资料保存和应用 | 官方导出导入、用户与左右手身份、部分失败恢复、收到有效 SDK 输出后的应用证明 | 手型保存在 SDK 用户档案；未重新采集实物标定 |
| CLI、标定和遥操作之间反复手动断开 | 明确目标后的交接、原资源释放确认、模型沿用及取消恢复 | 真实网络和长时间连接仍待设备验收 |
| 虚拟和实机入口重复、选手联动、画面尺寸 | 同一遥操作页面、模式无隐式连接、展示页独立型号、原尺寸设置 | 几何预览不能替代实物避碰与动作验收 |
| 维护跳页、无进度、错误显示成功、版本不准确 | 原位更新、实际字节校验流程、CLI 校验状态、SDK 回滚、固件错误与写后身份版本比对 | 本轮不下载或刷写真实设备固件 |
| 报告导出、采集与支持包失败恢复 | 实际源输出文件及 ZIP 字节、保存失败与显式重试、原始反馈未确认标记 | 采集帧由隔离替身提供 |

本轮固件服务复查覆盖兼容目录失败、明确重试、错误设备及退出码为零却没有确认目标版本的情况；这些情况均不得显示更新成功。不能据软件替身检查保证官方在线目录永远可用，或声称设备已经写入某个版本。

完整回归、Node 源执行回归、真实页面记录、非作者复查、构建与安装载荷、本机资料保留及源码同步结果保存在外部交付清单。旧失败和测试夹具错误保留，不将其改写成通过。本版未执行实物连接、固件写入、重新标定或实机跟随；相关稳定性和效果仍须接设备验收。

下载验证分别记录服务端文件完整性、浏览器保存和本机安装，不能互相替代。初次组合页面测试出现官方原 ZIP 保存取消；同一 ZIP 已在独立的最小 HTTP 对照中成功保存并核对摘要，完整支持 ZIP 与其他报告也已保存核对。组合源页面的最终传输对照单独记录在交付清单中，不拿最小对照替代完整页面验收，也不将原始失败改写成成功。支持包链接同时明确提示实际文件名，原包内容保持。
