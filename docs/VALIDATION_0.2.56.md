# 0.2.56 流程与并发复查

本轮从实际入口、后台状态归属和共享资源出发，先保存失败过程，再修复并由非作者采用不同操作顺序复查。用户界面沿用既有控件；没有增加诊断面板或要求用户操作后台命令。

## 更新与异步回复

设置中的 CLI、SDK 和控制环境分别管理请求代次。开始新操作或失联后，旧 GET、POST 和原生桥回调失去修改界面的资格；操作后的核对不复用操作前的在途查询，旧任务的 finally 也不能清除新任务。自动更新偏好必须由新读取的实际值确认。离线旧 busy 不再锁住只读重载按钮，检查挂起时不显示旧的绿色成功状态。

通过完整源页面和随机本机测试 HTTP 验证原失败顺序、反向回复顺序、重复点击、换页、关闭重开、语言切换、服务拒绝、失联和显式恢复。网络、SDK、CLI 和原生安装均由隔离替身提供；页面测试没有访问现用工作台或外部服务。

## 官方固件包与设备转接

开始转接前核对准确序列号、包摘要与有效凭据，再建立最多九十秒的私有转接能力。其它目录查询、包准备与会改变设备占用的维护入口不能替换正在转接的包；原目录凭据恰在转接中到期也不会把已开始的操作改成另一份档案。安装仍须重新确认设备、取得原维护占用、验证包与 CLI 身份，并由用户回答官方提示。超时、换设备、损坏包、旧凭据和旧 finally 不获得新权限，也不自动重连或重试刷写。

只读检查在保留占用后尚未启动就失败时，保留准确设备和私有的未启动证明；恢复只能解除同一占用。已有读取或未知读取不能借用该证明。旧写进程已经确认死亡、输出读取结束且设备资源回读匹配后，原传输才退役；活进程、未知退出、换占用或错误资源继续保留维护状态。恢复不会再次启动写入。

## 关闭、扫描与软件更新

退出的不可中断条件在任何工作区清理、下载取消或会话停止之前检查。拒绝关闭保留其它工作区，失败后可显式重试；自己的关闭意图不会覆盖另一任务的意图。

软件更新状态查询保持只读，仅将本进程身份和占用均准确的正常发现识别为可让出的任务。显式安装、助手预检和关闭在共享门锁外短时等待该发现退出；活动 Viewer、SDK、兄弟工作区及未知清理仍受原保护。一次更新关闭使用同一截止时间，覆盖子 HTTP、等待和回调；超时后不继续新的停止、进程关闭或窗口销毁动作。已经发生的清理事实保留，不倒推为从未执行。

## 提醒与验收边界

固件提醒按当前整个设备工作区集合中的实际 SDK、Viewer 或标定会话过滤。发现记录、选择和断开的旧身份不能充当连接；已连接的其它工作区仍可获得提醒。服务端保留历史事实，前端使旧连接上下文的在途回复失效；工作台、CLI 和 SDK 软件提醒保持独立。

最终全量软件测试、独立复查、编译代码和网页资源比对、本机安装及资料保留结果，分别保存在本轮外部交付清单。各套件有重叠，不相加作为验收结论；原失败记录、修正后的夹具和环境跳过均保留。

全量首轮出现过一次 Windows 映射库替换权限错误，单模块重跑通过，原占用来源仍未确认。另以隔离文件及受控共享句柄验证保存、预设保存和删除失败时原文件、版本与预设保留，释放占用后显式重试成功；没有跳过原测试、弱化断言或盲目增加重试。

本轮没有为检查连接手套、刷写固件或启动实物动作，也没有再次下载固件。此前已验证的官方 ZIP 完整性不等于硬件兼容或刷写完成；真实刷写、重启、标定与遥操作效果仍须接入设备后单独验收。官方带硬件版本筛选的目录返回 404 这一原始事实没有被改写。
