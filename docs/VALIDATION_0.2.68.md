# 0.2.68 验证范围

此次针对实际 SDK 报错 `Parameter not set: calibration.hand_model_path`，以及遥操作页缺少明确开始和重试入口。此前测试替身未准确模拟 SDK 参数未设置的异常合同，不能据此认定真实设备连接已经可用。已有人员、官方标定原始文件和其它人员资料继续保留。

接口依据为本机已保存的官方 SDK 2026.10.26 类型文档及官方示例。导入人员资料与配置在线 IK 模型参数是不同操作。当前实现仅在明确使用已验证模型、实际人员/设备/左右手已核对后应用准确永久模型路径；只有合法空路径或 SDK 类型与完整参数名匹配的未设置错误可触发此应用。应用后读回路径并再核对内容，完成前不订阅。已有不同模型、断连、错误类型、设置失败、回读为空或内容不同、文件改变均继续失败并清理准确候选。

测试替身改为真实合同形状：参数初始抛 SDK 未设置异常，官方 setter 改变同一资源，后续 getter 和订阅读取该状态。范围包含保存与重复接入、两名人员资料保留、错误身份及错侧拒绝、冲突模型不覆盖、设置失败和错误读回、明确重试与退出。由非作者独立执行 Handler、Controller、Bridge 和 worker 的不同顺序验证，设备、SDK、CLI 和进程外部边界隔离。

界面复查包括无设备时选择手套、明确开始、参数失败不误导重标定、重新接入并使用已存模型、保留虚拟页签、切换实机后明确配对和跟随、暂停与断开。开始入口继续调用同一设备用途切换，不恢复低层重复连接或自动跟随。标定和灵巧手单独展示的相关流程按改动范围回归。

软件回归、构建源码一致性、安装后版本和页面载荷、用户资料保留及现有源码分支同步结果保存于本机交付记录。合成检查不能代替真实设备稳定性、物理动作或固件写入验收；本文不表示安装包已公开发布。
