# 0.2.37 验证范围

本轮继续审核设备会话、标定接续、异步取消、失败恢复与关闭软件。先保留可复现反例，再修复并由其他子 Codex 交叉复验；不增加客户模式或常驻技术栏。

修复的行为：

- 从现有官方 Viewer 进入标定时沿用准确手套，发现记录过期或旧草稿不再清空当前设备。
- 成功切换后的返回结果由服务器绑定切换前后会话；前端仍拒绝其他设备、新连接、错误或伪造回执，保留原嵌入页。
- 取消切换只影响准确 Viewer、随机尝试与原 SDK 会话，不能断开已经进入预览或跟随的会话，也不能把旧回复写回新会话。
- 跟随指令发送结果未知时保持停用未确认。仅同会话、同目标、同 nonce 的零分派拒绝可以解除等待，不从过期状态推断停止。
- 切换佩戴者须由 SDK 确认实际用户；失败会话保留原设备的明确暂停、断开入口，重叠归属仍阻断。
- 配对等待期间显式选择另一个目标会使旧配对失效；不覆盖后来的选择。状态读取只加载小型绑定文件，不重复读取整套映射库。
- 合法切换后须等准确新会话的状态实际渲染才恢复操作；同一会话的父标签更新不重复清理为离线。保存绑定后的显式连接、准备仅在准确回执、原 SDK/用户/模型和本次选择均未变化时各接续一次，不重试跟随。
- 已结束但清理未确认的标定不能被视为空闲并关闭、重载或更新软件；成功清理只确认原准确 run、Job 与 token。
- 修复无连接状态下的空值界面异常。

软件回归、生产父页及嵌入页浏览器测试、冻结源码、最终安装包、同 GUID 覆盖安装分别记录在外部 `outputs/audit-0237`。HTTP 拦截和 fake SDK 场景验证软件流程，不等于实机验收；失败和撤下候选证据保留。

第一轮完整隔离软件回归 1453 项通过相应门槛后，独审新增设备目录改选的真实事件反例：旧操作可能恢复之前的选择。已补齐选择版本校验，首个冻结候选未构建或安装，证据保留。最终重新完整回归 1453 项，1451 通过、2 项原条件跳过，0 失败或错误；执行用时 61.277 秒，含隔离准备的记录用时 62.266 秒，Python 源运行中未变。专项与两轮回归不叠加计总数。

升级前实际 0.2.36 留有 `can_continue` 空值界面错误，原失败记录保留；其后仅读取同一安装身份和配置作为保留基线，明确标为已有错误，不能称旧版功能验收通过。升级后仍执行严格无界面错误、配置保留和实际安装文件核对。

本轮不打开真实手套，不采集标定、不清零、不发送电机指令。真实佩戴六动作的模型质量、Windows 至 SDK 的实机接续、实物跟随及停止、多设备物理并行仍待用户重连验收。映射的实物防穿模/避碰、独立原生任务窗口、原生失焦磨砂效果和网络二进制更新仍不声称完成。
