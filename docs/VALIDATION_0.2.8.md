- Python 全套 432 项：430 通过、2 项因平台/可选运行条件跳过；连接流程 5 项通过，前端脚本语法检查通过。
- Linux 控制环境独立运行 9 项会话/标定测试，包括共享/排他用户锁、设备序列号占用、左右/代际不匹配拒绝及锁内用户复核；全部通过。
- 两个真实 Python 子服务完成工作区创建、独立端口/身份、状态、保活、全部停止请求及关闭。无真实设备，用此结果验证软件隔离，不作多手实机验收。
- 模拟 SDK 验证一代手套跟随的实测角度起步、官方 LowPass 调用、源失联停止，以及断开配对手时不关闭手套。

## 本轮发现并修复

- 二代控制分派过早释放序列号锁，可能让另一工作区重复占用；现在保留到实际控制进程退出。
- 一个慢工作区可能阻塞其他工作区的保活；改为每工作区独立任务，避免连带超时。
- 手套接入和标定修改全局 SDK 用户可能相互干扰；增加会话锁及短时用户选择锁，连接后恢复原用户。
- 点击标定后的预检结果可能因另一工作区切换用户而失效；Linux 启动端在持有排他锁后再次核对命名用户和当前标定状态。用户已变更或未经许可出现新模型时，不启动采集，也不覆盖。
- 停止 Windows 启动器不等于取消 Linux 标定；改为把取消传到真正的官方进程，等待设备释放。
- 新的六姿势脚本和样式未进入静态资源列表；实际浏览器发现后修复，并新增入口资源服务检查。
- 多工作区选择框每次刷新重建会打断选择；仅设备/名称/语言变化时重建。
