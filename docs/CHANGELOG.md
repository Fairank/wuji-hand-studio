# 更新记录 / Changelog

## 0.2.35 — 删除多余画面模式

- 删除客户不需要的三来源切换栏，仅保留一块自动选择真实来源的画面；有目标反馈后不以生成目标替代失效实测。
- 保留画面尺寸调节、明确的跟随/暂停/断开，以及标定资料接续与设备任务管理。
- 独立碰撞显示实验不作为客户模式；不承诺实际映射或实物已经避碰。
- 0.2.34已试装但最终验收未完成，旧包和失败证据保留；新安装、回归与源码按0.2.35分别核对。

## 0.2.34 — 设备任务、标定接续与流畅界面

- 统一字体、层级、控件、表面与间距；设备历史折叠，单手预览与多手主操作上移，窄屏减少导航占位。
- 标定改为单任务主画面，突出原版参考图、当前动作与真实进度；成功和需处理的问题保留在当前任务中。
- 修复状态刷新与单手/多手跨页重挂造成的选中框瞬移；统一短过渡并尊重减少动态与高对比度。
- 模型首帧、缺画面和过期状态区分；动态显示与错误提示按当前语言更新。
- 手套与官方CLI画面支持软件内拖动、键盘和尺寸菜单调整，分别保存高度；原画面/终端节点和会话保留。
- 本次严格完成的官方标定可沿用至遥操作；复用官方档案导出、预览、导入与内容核验，沿用准确用户和手型，冲突不覆盖。
- 已连接设备生成任务标签，明确配对、解绑、停止与断开；支持双分区、拖放、软件内浮动/停靠，关闭视图不关闭会话。多手任务复用原编组协议。
- 增加独立碰撞约束预演，仅用于显示；映射目标、实测反馈和发送目标各自保留，软接触和第一代模型覆盖限制可见。
- [软件验证边界](VALIDATION_0.2.34.md)。没有替换官方标定算法，也没有将预演结果写入实机控制。

## 0.2.27 — 手套标定工作流与明确的可视化入口

- 手套标定改为紧凑的设备、用户、侧别准备流程；就地发现，过期结果不冒充在线，Default 用户明确引导创建或切换命名用户。
- 准备状态按元数据、用户、身份、模型、已有会话分别解释；错误和恢复入口靠近开始按钮。启动前补齐当前默认用户与未知模型检查，Linux 内部身份和排他锁复核保留。
- 启动阶段显示身份核对，收到官方事件后才显示采集/求解；显示官方当前动作、质量及进度，只有成功result与正常退出同时满足才确认完成。
- 覆盖同意绑定具体用户、手套编号和左右手；切换上下文后清除，避免旧确认用于另一套标定。
- 官方可视化默认实时设备；无设备查看器作为明确的可选入口，不接入数据、不标定、不自动结束已有会话。
- 移除自动扫描开关：未接入时每5秒查找，确认成功接入后暂停；点击「添加设备」恢复查找。扫描结果始终需要手动选择及明确连接，删除旧版自动连接设置和定时连接逻辑，旧偏好不再触发接入。
- 原生官方广播发现可与已核实的新鲜纯灵巧手反馈并存；手套预览、运动、标定、诊断、停用未知及Viewer占用仍保持原门禁，不为扫描自动断开会话。
- 设备分类、播放目的地、画面来源、字符选择及关节选择复用连续平移的选中背景；确认勾选与禁用按钮采用共享样式，保留键盘、减少动态和高对比度语义。
- 保持同一软件身份及配置，CLI/SDK来源与设备控制参数不变。[操作说明](CALIBRATION.md) · [软件验证范围](VALIDATION_0.2.27.md)。实机采集与模型效果由用户重新连接后单独验收。

- U3：校准操作错误与刷新错误分离；刷新失败保持官方状态待核对，成功刷新只清读取错误。

- 中断或哈希不符的安装缓存可重新暂存，完整校验后原子替换；失败不发布半成品，关闭失败或退出超时不启动安装器。
- 构建器核对缓存程序自检中的产品身份与版本，使用独立自检文件，拒绝缺失、无效或旧版本结果。
- 窗口尺寸在同一锁内成对读取并原子保存，避免并发回调保存混合宽高或损坏配置；不改变窗口、DPI 或页面选择。
- 官方标定的错误和取消事件优先于正常退出码，保留真实错误原因，不因退出码为 0 显示完成。
- 提供 Windows 隔离软件检查 CI 模板：语法、模拟升级/缓存/构建失败及选定回归。当前 GitHub 凭据不含 workflow 权限，模板放在 `ci/windows-checks.yml.example`，未启用远端 Actions。模板、局部模拟、安装版和实机验收分别记录。
- 保留一个工作台、原安装身份、用户数据和原生磨砂；不恢复桌面采集或液态折射，不新增无关 Mac/Ubuntu 验收结论。
