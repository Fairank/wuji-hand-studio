## 实际修改

- 接入前相同 327 份控制端文件的完整校验，从逐文件跨系统读取改为控制端一次完成。旧方法实测 12.36 秒，新接口两次为 4.91 秒、1.59 秒；这是文件准备耗时，不是完整设备连接耗时。
- 同次转接复用已锁定的标定快照，将 9 次 CLI 调用／3 次导出减少至 6 次／2 次。接入前的最终人员、模型内容和取消检查仍然执行。
- 官方画面沿用已有私有控制台，请求 CLI 正常退出再转接。超时回收、缺少退出确认或非零退出不会被当作成功。
- 失败连接的准确会话已经确认退出时，结束残留的等待状态。没有新增自动连接或后台重连，保留原界面和设置。
