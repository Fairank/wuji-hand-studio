# 0.2.77 手发现时间与代码审查

成功查找灵巧手时，SDK 发现结果使用自己的 `hands_at` 观测时间，不再借用较早的手套扫描时间而立即过期。手扫描失败不会更新时间或给旧手套续鲜；完整扫描只有全部解析成功才发布时间与列表。旧工作端缺少该字段时沿用原时间，明确空值不借另一列表时间。

使用真实 worker、Bridge 与目录构造函数及隔离 SDK/进程替身复现预览超过30秒后新手被误判过期，并验证后续失败、空成功、部分解析失败、兼容状态和独立时间。非作者使用不同顺序复查，实际设备原始识别质量未由这些替身认证。

加入 `.github/workflows/code-review.yml`、PR 核对表、`src/AGENTS.md` 审查规则和统一 `scripts/run_review.py`。本地与 CI 使用同一入口，运行完整 Python、Node、语法、运行器自测与现有连接检查；失败、被拒绝操作或受检源码变化返回非零。CI 不构建或发布安装包，不启动实物，不新增模型密钥。Codex 账号自动审查开关及 GitHub 合并规则仍须在相应服务配置，不因提交文件便冒称已启用。见 [CODE_REVIEW.md](CODE_REVIEW.md)。

现场已保存通电和拔出后的只读状态。通电快照中一个 ASIX 网口有100 Mbps链路但为自动私有网段，原设备网段配置在另一只未连接的 Realtek 网口上；这提示实际相连网口的配置需要核对，不能在未确认手本体 IP 前判为唯一首因或自动改网络。驱动、固件和 SDK 是不同层；没有因扫描空列表而安装不明驱动、刷固件或猜地址接入。

原生 Windows 发现成功后列表为空的实物原因仍待确认；这次时间戳修复不冒称解决该现场原始空列表。没有新真实设备连接、网络探测、网络配置修改、SDK/CLI 验收或实机动作。原样式与导航不变，设置和标定资料在交付时另行核对。
