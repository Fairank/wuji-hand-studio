# 0.2.50 固件升级环境与错误反馈验证

本次实际失败记录显示：官方工具完成检查并取得候选固件，用户确认后以非零状态退出，准确设备行的 Detail 为 `HOME not set; cannot locate firmware cache`。旧界面只显示一般失败，原终端中的具体原因没有进入结果摘要。

## 修复与软件验证

- Windows 没有 HOME 时，仅给固件子进程使用当前用户的 USERPROFILE/Home；已有明确 HOME 保持。不能使用软件检查临时目录或应用资料目录代替，以免 SDK 用户与标定资料分叉。
- 原版 ConPTY 启动接口接收完整子进程环境，目录设置、禁止自动组件检查及遥测选项进入实际子进程，不修改父进程环境。
- 实际 Windows ConPTY 验证仅运行隔离 Python：核对 HOME/USERPROFILE，并在 QA 目录写入小标记后退出。不启动真实 CLI 设备命令，不读取真实 SDK 档案，不连接设备或刷写。
- 原始终端输出在退出后仍保留。只有进程确实退出且状态非零时，才从完整已知官方表格中提取精确设备的失败原因。其他设备、未知格式、缺表头或底边框、重复冲突均回退到原文，不猜测成功或百分比。
- 退出0仍必须按照原逻辑读回同一设备版本；失败文本、确认输入或窗口关闭都不能代替写后核验。失败后的重新检查与升级均由用户明确触发，不自动输入确认，不自动重试。

隔离全量回归2104项：0失败、0错误、2项环境跳过。独立环境检查包含真实 ConPTY 子进程，父进程环境保持不变。页面失败提示、准确设备绑定与显式重试另由独立流程复查。构建、实际装入文件与安装后版本核验记录在外部交付清单。

## 实物范围

本轮没有重新连接或刷写真实手套，没有宣称固件已更新到目标版本。环境与软件流程修复完成后，仍需用户在软件的官方窗口中确认升级，并以真实读回版本判定结果。原始失败证据保留。
