# 0.2.14 — 操作控件与官方流程说明

本版只调整界面、导航与说明。电机控制、SDK 标定、求解器与存储协议未改。原生安装后的最终验收摘要记录在 [Windows 发布页](https://github.com/Fairank/wuji-hand-studio/releases/tag/v0.2.14-windows)。

## 软件检查

- 485 项 Python 检查：483 通过，2 项按已有平台/条件跳过。未通过真实硬件执行这些检查。
- 三个新增/修改脚本通过 JavaScript 语法检查。打包后 147 个界面文件与源文件 SHA-256 全部一致。
- 浏览器：连接浮层的连接/标定/映射入口进入正确分区并关闭浮层；键盘 Esc 关闭并返回焦点；中英文标题、描述与图标保留；浅色、深色、减少动画检查。
- 文字选择窗可以打开/关闭；校准设置正常展开；数值宫格选择食指第二列后，图解正确切到指根侧摆。最终复查页面没有控制台错误或水平溢出。
- 原生更新使用同一安装 ID、程序路径与用户数据；发布前检查 960×680、1308×864 窗口和安装资产一致性，结果在上述发布页汇总。

一次中间构建在通用组件尚未写入时运行了检查，报告缺少 action_row.js；安装版未使用该中间状态。组件完成并审核后全套检查通过。私有数据、凭据、训练权重均未进入发布文件。

## Claude 使用记录

仅委托通用图标导航行，不委托设备控制决策。首次请求因连接拒绝退出；相同通用需求重试成功，实际模型 `claude-opus-5-5`，effort `max`，退出 0。主助手审查无网络/存储/计时器、文本构建、链接约束、禁用/焦点语义，适配样式类名后集成。没有外发私有源码或设备数据。

## 官方功能边界

六姿势采集、稳定性/约束判断与求解继续由官方 CLI 完成；工作台展示其反馈。工作台宫格图是示意图，原版 Studio 动作插图、人体 URDF 画面、触觉 Visualization 和全传感器调试录制没有在本版搬入。真实手套端到端标定与实机跟随仍需设备验收。

官方文档已核对：手型标定按用户/左右侧持久保存；触觉标定另按用户/手套编号保存；跨电脑或控制环境需要导入档案。映射参数修改骨架到机械手目标的转换，不写入手套传感器或改写手型标定。详细依据见 [标定与映射](CALIBRATION_AND_TUNING.md)。
