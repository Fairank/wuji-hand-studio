# 0.2.69 验证范围

本轮修复设备会话显示、已确认左右手传递、预览额外滞后、官方标定失败提示和已依赖 SDK 接口的更新兼容预检。继续复用现有用途切换、官方 CLI/SDK 与会话事实，不增加连接管理器、后台重连或自动实机动作。

正在标定或清理未确认的准确 run ID 与设备编号保留在目录；会话卡保持真实过期状态，不授予新连接权限，确认结束后移除。SDK 已连接且接收中的侧别只绑定准确设备与会话；官方原始扫描缺少字段时，标签和标定选择使用同一当前身份投影。相反或过期证明不自动覆盖。

几何预览不再固定每个显示帧最多追赶 0.12 弧度。合法 SDK 目标作为显示目标，仍由原配置无关位移界、逐候选碰撞检查、时间预算和关节限位决定已证明的显示姿态。纯数值检查验证无碰撞时同帧跟到目标，以及碰撞、预算耗尽和过期数据仍拒绝伪造姿态；未把替身当真实 MuJoCo 几何或物理精度验收。

实际只读标定记录为官方捏合动作等待超时。界面优先显示当前结构化错误消息和最后一次指标，不更改官方阈值、不假称已完成或自动重试。测试覆盖失败、重新开始、上下文改变、离线及无效指标。SDK 兼容探针补齐模型路径、异常类型和导出接口，只检查能力而不构造设备；未知 CLI 事件版本保留原始记录并拒绝生成标定成功证明。

各项先保留失败复现，再执行相关永久回归与不同顺序的非作者复查。实际页面采用真实协调器和目录数据的隔离重放；SDK、设备、进程与网络边界按测试范围替换。全量回归、打包源码一致性、安装后版本和载荷、资料保留及源码同步结果另记本机交付记录。

本轮未主动连接真实设备、启动实物动作或执行真实 SDK/CLI 更新；真实设备稳定性、实际手型映射精度和真实碰撞效果仍需实物验收。兼容预检降低已知接口缺失风险，不承诺未来任意官方版本均无问题。
