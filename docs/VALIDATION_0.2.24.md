## 真实设备与软件测试的区别

0.2.23 实际通过 Windows 官方 CLI 发现了右手手套，Linux SDK 直连也收到了新帧；官方标定列表已经能显示同一设备。原版 Viewer 进程、HTTP 服务和正确序列号报告通过，但数据流端口 5061 被 Chromium 以 `ERR_UNSAFE_PORT` 拦截，因此该版原版实时画面没有通过验收。欢迎页不能当作传感数据画面。

0.2.24 针对浏览器限制端口转接到仅本机的安全临时端口，不更改浏览器安全策略。用户在此修复前已断开手套，后续验证均为软件或明确标注的合成数据；本版真实手套的完整原版画面仍需下一次接入复核。

没有开始或完成真实手型标定。Default 用户不能执行官方手型标定；用户需佩戴手套，创建或切换命名用户、选择设备和左右手，再按官方实际步骤完成采集。未连接或使能机械手，未执行触觉清零、遥操作跟随或固件升级。

Windows 原版 Viewer 与 Linux SDK 映射使用的用户环境不同，本版不自动迁移标定档案。Linux 标定结果用于工作台的 Linux SDK 映射，不能据此声称 Windows 原版 Viewer 已加载同一份模型。
