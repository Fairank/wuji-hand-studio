# 0.2.44：准确显示无设备扫描状态

0.2.43的实际已安装SDK查询与逐文件验证均通过；自动和手动扫描也正常完成，但现场未发现可选设备，没有执行实物连接或往返切换。查看真实页面截图又发现，扫描占用被误计入设备会话，显示“已有会话仍在设备任务中”，实际任务列表为空。旧结果及截图保留在 `outputs/customer-flow-0243`。

0.2.43全量1,802项结果（1,800通过、2项跳过）按冻结清单比对Python源码完全一致后继承，不称本版重新运行全量；本版生产源码差异仅为库存页面脚本和版本号。构建阶段再核对源码、前端文件、安装包及已安装文件的一致性。

软件验证、构建文件、安装包、正常桌面更新、安装后实际档案读取和无设备页面复查分别保存在 `outputs/customer-flow-0244`。现场没有可选设备，因此实物选择、CLI与SDK往返切换、佩戴标定质量和电机跟随仍没有验收证据。
