# Windows 手套连接与官方画面（0.2.24）

这里说明 0.2.24 源码中的连接方式，不表示设备标定或实机动作已经验收。

## 先看哪一个入口

- **空窗口**：不接设备也能打开原版 Viewer，但没有手套数据。
- **实时设备**：查找并选择真实序列号，再启动官方画面。右上角的“连接机械手”只负责机械手反馈，不连接手套。
- **SDK 手套预览**：用于工作台的映射预览，与官方 Viewer 是不同的设备会话。

手套或接收盒通过网线接到 Windows 的 USB 网卡后，在“连接与校准 → 官方可视化 → 实时设备”中查找。若正在运行纯 SDK 预览，明确点击“关闭手套预览并查找”，等待退出确认后再扫描；不会自动结束遥操作、机械手动作或未知会话。不要同时让 SDK 预览与官方 Viewer 占用设备。

扫描为空时，先看 Windows 中对应有线网卡是否已连接。网口没有链路时，换界面或重复启动 Viewer 不会产生设备数据。地址改过、网段不通或设备没有回应也可能导致扫描为空；工作台不把空列表解释为标定失败。

## 为什么改用 Windows 原生发现

在 **Windows + 内置 WSL、默认官方 CLI 路径**的配置下，设备发现和原版实时 Viewer 从 Windows 主机直接运行官方 Windows CLI，避免依赖 WSL 的广播发现。用户明确指定的自定义 CLI、远程控制端及本机 Linux 仍保留各自配置。

第一次**明确点击查找**时，工作台按需下载官方 CLI **2026.10.12** 的 Windows x86_64 发布包，核对固定 SHA-256，安全解压，再执行版本和帮助检查。后续使用已核验缓存；不会在导入模块时下载，不安装 Studio，不更改全局 WSL 配置。

默认独立目录为：

```text
%LOCALAPPDATA%\WujiStudio\official-cli-native\versions\2026.10.12\
```

其中保留官方 ZIP、原版 `wuji.exe`、发布元数据和 `manifest.json`。清单记录官方下载地址、归档摘要、可执行文件摘要及软件检查结果。它不覆盖 Linux CLI 的版本选择，也不替换 SDK、固件或用户档案。

官方实时画面使用明确选中的序列号，并带 `--no-zero --no-open --jsonl`。不追加电机使能或动作命令；Glove 的官方可视化仍会设置数据流频率，因此不称为完全零写入。

## 标定仍在原来的 Linux 用户环境中

原生 Windows CLI 负责上述发现和显示；官方手套标定仍使用原有 Linux CLI 与用户档案，不另建一套 Windows 标定用户。

Windows 原版 Viewer 使用 Windows 侧的 SDK 用户环境；本版不会把 Linux 标定档案自动复制或导入到 Windows。Linux 中完成的标定用于工作台的 Linux SDK 映射预览，不能据此宣称原生 Viewer 已加载同一份手型模型。查看原始传感数据与验收标定后的映射是两项不同检查。

标定通过本次发现的 `--address` 连接，开始前由官方 SDK 核对设备类型确为 `WujiGlove`、序列号完全一致、左右手一致。身份变化、地址无效或任一核对失败都会显示错误，不把手套接错到另一个用户或另一侧。按地址连接解决的是广播发现路径，不能代替可达性和身份检查。

未选用户、尚未完成或标定报错时，不显示为“已标定”。接收到骨架、原始触觉矩阵或打开 Viewer，也不能证明标定已通过。

## 更新和状态边界

0.2.23 实际发现了设备，但原版画面因数据端口 5061 被 Chromium 拒绝而未通过验收。0.2.24 在原版 HTTP 或数据端口属于浏览器限制端口时，使用固定目标、仅本机可访问的临时端口转接。转接随会话关闭，不记录或改写传感数据，不改变浏览器安全设置。其依据是 [Chromium 的端口规则](https://raw.githubusercontent.com/chromium/chromium/main/net/base/port_util.cc)；本机 TCP 能探通不代表浏览器可以使用。

Windows 原生版本目前固定为 **2026.10.12**。以后采用新版本，要先审核官方 release 地址、文件大小、归档和可执行文件摘要，以及所需命令接口，再更新源码中的 pin。现有 Linux CLI 自动更新器不会隐式升级这个原生 pin。

“CLI 运行中”、启动报告、端口可连和画面已载入，只确认相应启动步骤。官方接口没有持续报告数据新鲜度，工作台保留“新鲜度未报告”，不把进程存在或旧画面当作当前反馈在线。

重新载入画面、切换空窗口或隐藏页面不等于停止设备会话。结束官方采集时使用“停止可视化”，以确认退出的实际结果为准。

实现依据：[官方 CLI v2026.10.12](https://github.com/wuji-technology/wuji-cli/releases/tag/v2026.10.12)、`src/native_cli.py`、`src/official_device_discovery.py` 和 `src/calibration_address.py`。
